## 一、任务A：障碍物 3D 代理（新建 obstacle_visual_3d.gd）

- 位置：`scripts/battle3d/visual/obstacle_visual_3d.gd`（与 `shield_visual_3d.gd` 同目录同写法）
- `setup(host)` 只读消费宿主公开数据：`shape_type` / `element_color` / `_cached_width` `_cached_height` `_cached_radius` / `obstacle_hp` / `max_obstacle_hp`
- **形状映射**（消费 2D 已有 shape_type，与原作技能表天然对齐）：

| shape_type | 3D 体 | 对应原作技能（填写版） |
|---|---|---|
| rect | 立体长墙盒 BoxMesh（宽×墙高≈40×厚10） | 石墙·棕灰 / 金刚壁垒·金 / 零度冰墙·冰蓝 / 防守版荆棘网络·绿 / 风墙·紫 |
| circle | 竖立圆柱 CylinderMesh（半径×高≈50） | 黄土墙盾"圆柱形图腾" / 零度冰柱 |
| crescent | 弧形分段墙（沿弧排布小盒） | 钻石壁垒"月牙形墙" / 蔷薇花园"优弧圆环" |

- 颜色：`element_color`（大地=棕灰=岩石墙、草木=绿=蔷薇、冰雪=冰蓝、金刚=金、梦幻=紫——与 21表§五配色数值同源，第二真相禁令=不抄数值只读宿主）
- **看到消耗**：①耐久梯度变色（元素原色→橙→红，同盾先例）②头顶 Label3D 数字牌「当前HP/最大HP」，球磨墙时数字实时下降
- 位姿：`sync_from_2d(pos, rot)`，(x, 0, y) 单位制铁律 1:1 零换算
