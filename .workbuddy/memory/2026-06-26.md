## 17:11 — 大相机模型仍不可见根因分析 + ModelSlot 父容器重写

### 根因
`_make_3d_player()` 用 `_find_first_node3d()` 深入 GLB 内部找第一个 Node3D 并直接改其 Basis。
这会破坏 GLB 骨骼/网格层级结构（可能是 Skeleton3D，改了它的 Basis 后骨骼坐标系与动画数据冲突 → 模型消失）。

对比 `battle/player.gd`（正常工作）：ModelSlot 是**父容器**设 Basis，GLB 实例原封不动挂子节点。

### 修复 — `_make_3d_player()` 重写为 ModelSlot 方案
1. 创建 `slot` Node3D（ModelSlot），直接设 `Transform3D(Basis(1,0,0, 0,0,-1, 0,1,0), ZERO)`
2. slot.scale = 0.55
3. GLB 实例 → `slot.add_child()`（不改内部节点）
4. 色环 → `root.add_child()`（不受 ModelSlot 旋转影响）
5. 兜底 idle FBX 同样挂 slot
6. 新增 `_find_first_node_of_type()` 诊断函数，打印首个 MeshInstance3D 的 aabb/visible
7. `_play_3d_proxy_anim()` 补 null 守卫

## 20:40 — ModelSlot Basis 修正 + 4动画合并（解决躺着 + 无动作）

### 现象
用户反馈：模型能看到了，但是**躺着**，且**没有动作**（只有 idle 一帧）。

### 根因分析
1. **躺着**：ModelSlot Basis 设为 `Basis(1,0,0, 0,0,-1, 0,1,0)`（绕 X 轴 -90°），
   这是对"趴着"模型（上=+Z）的修正。但猪猪侠 GLB 导出时可能已经站立，
   这个旋转反而让它躺下（上方向 = 世界 -Z）。
2. **无动作**：`_make_3d_player()` 只加载了 body GLB，没有合并 run/throw/catch 三个动画 GLB，
   AnimationPlayer 里只有一个动画（或没有）。

### 修复方案（完全对齐 battle/player.gd）

#### 1. ModelSlot Basis 改为单位矩阵
```gdscript
# 旧（绕 X 轴 -90°，导致躺着）
slot.transform = Transform3D(
    Basis(Vector3(1,0,0), Vector3(0,0,-1), Vector3(0,1,0)),
    Vector3.ZERO
)
# 新（不旋转，假设 GLB 导出时已站立）
slot.transform = Transform3D(Basis.IDENTITY, Vector3.ZERO)
```
若模型仍躺着，再试 `Basis(Vector3.RIGHT, deg_to_rad(-90))`。

#### 2. 4动画合并逻辑（从 player.gd 搬过来）
在 `_make_3d_player()` 里：
1. 加载主 GLB → 挂到 slot
2. 找 AnimationPlayer → 存到 `root.set_meta("anim_player", ap)`
3. 重命名默认动画为 `"idle"`（`_rename_default_anim_to()`）
4. 合并 run/throw/catch 三个动画 GLB → 主动画播放器（`_merge_proxy_animations()`）
5. 设置 `ap.process_callback = AnimationPlayer.ANIMATION_PROCESS_PHYSICS`

#### 3. 新增三个辅助函数（插入在第415行前）
- `_hide_mixamo_helpers(root: Node)` — 隐藏 Icosphere 参考球
- `_rename_default_anim_to(ap: AnimationPlayer, new_name: String)` — 重命名默认动画
- `_merge_proxy_animations(ap: AnimationPlayer, slot: Node3D)` — 合并三个动画 GLB
- `_find_animation_player_static(node: Node)` — 静态递归查找 AnimationPlayer

#### 4. `_physics_process` 加入 idle/run 自动切换
在末尾（`_update_debug_label` 前）加入：
```gdscript
var current_proxy = (_proxy_a if controlled_player == player_a else _proxy_b)
if current_proxy and is_instance_valid(current_proxy):
    var ap: AnimationPlayer = current_proxy.get_meta("anim_player", null)
    var cur_anim: String = current_proxy.get_meta("current_anim", "idle")
    if ap != null and is_instance_valid(ap):
        var moving: bool = controlled_player.velocity.length() > 10.0
        var target: String = "idle" if not moving else "run"
        if target != cur_anim and ap.has_animation(target):
            ap.play(target)
            current_proxy.set_meta("current_anim", target)
            var a = ap.get_animation(target)
            if a: a.loop_mode = Animation.LOOP_LINEAR
```

#### 5. `_input` F1/F2/F3 改为直接操作 proxy 的 AnimationPlayer
```gdscript
# 旧（错误）：controlled_player.play_3d_action(anim_name)
# 新：
var px = _proxy_a if (controlled_player and controlled_player == player_a) else _proxy_b
if px and is_instance_valid(px):
    var ap: AnimationPlayer = px.get_meta("anim_player", null)
    if ap and ap.has_animation(anim_name):
        ap.play(anim_name)
        px.set_meta("current_anim", anim_name)
        var a = ap.get_animation(anim_name)
        if a: a.loop_mode = Animation.LOOP_NONE  # throw/catch 不循环
```
