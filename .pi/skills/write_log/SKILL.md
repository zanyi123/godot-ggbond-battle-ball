# 工作日志规范化写作技能

## 技能说明
每次对话结束后，将工作内容整理到当日工作日志（`工作日志/2026-XX-XX.md`）。

## 日志格式

```markdown
# 决竞球 Battle Ball - 工作日志

## Tips（置顶）
- 每次对话写入当日工作日志
- 记得更新前一天的任务状态

---

## 2026-XX-XX

### 今日完成
- [完成点1]
- [完成点2]
- [完成点3]

### 待完成任务
- [ ] [待办1]
- [ ] [待办2]
- [ ] [待办3]

### 下一步方向
- [方向1]
- [方向2]

---
```

## 要求

### 今日完成部分
- **简洁列表**：每行一个实现点
- **不写代码**：不贴代码块、不写详细实现步骤
- **不写几百行**：保持简洁，通常20-30行以内
- **聚焦成果**：只写完成了什么，不写过程细节

### 待完成任务部分
- **简短列表**：列出未完成的任务
- **优先级排序**：重要的放前面
- **用方括号标记**：`[ ]` 表示未完成，`[x]` 表示已完成

### 下一步方向部分
- **简短说明**：下次对话要做什么
- **明确方向**：具体、可执行
- **关联待办**：指向待完成任务

## 示例

### 错误示例（又臭又长）
```markdown
## 2026-06-14

### 今日完成
- 发球速度差异化功能
  - 数据层：球员差异化配置
    - 为7个球员添加 ball_speed 字段
    - 猪猪侠：420
    - 菲菲：480
    - ...
  - 球员层：读取发球特性
    - 新增方法：
      ```gdscript
      func get_base_ball_speed() -> float:
          if char_data.has("ball_speed"):
              return float(char_data["ball_speed"])
          return 400.0
      ```
  - 球层：使用球员基础速度
  - ...

### 待完成任务
- [ ] ...
```

### 正确示例（简洁明了）
```markdown
## 2026-06-14

### 今日完成
- 发球速度差异化：球员个性化球速 + 标签系统叠加
- 7个球员添加 ball_speed 字段（370-480）
- player.gd 新增 get_base_ball_speed() 方法
- ball.gd launch() 读取球员基础速度
- 开发工具新增发球球速滑块（棕色，300-600）
- 角色系统UI重构：滚动容器 + 自动排版规范
- character_system.gd 添加 stat_keys 类成员数组
- 建立排版规范：添加新属性只需修改1个数组
- 修复语法错误：stat_keys 作用域问题

### 待完成任务
- [ ] 角色系统UI显示验证（7个属性条 + 滚动）
- [ ] 比赛中发球速度验证（菲菲480 vs 猪猪侠420）
- [ ] 标签系统叠加验证（基础×倍率）
- [ ] 开发工具新建角色验证（默认400）

### 下一步方向
- 测试角色系统UI滚动和显示
- 测试比赛中发球速度是否符合球员值
- 测试标签系统叠加是否正确
```

## 注意事项

1. **不写技术细节**：不贴代码块、不写算法步骤
2. **不写重复内容**：同一天不要重复记录
3. **更新前一天状态**：查看前一天日志，更新已完成任务
4. **保持简洁**：通常20-30行以内
5. **聚焦成果**：只写完成了什么，不写怎么完成的

## 技巧

- 用动词开头：完成、修复、新增、重构、实现
- 用简短描述：如"新增发球速度差异化"而不是"发球速度差异化功能的完整实现"
- 分类整理：相关内容放在一起
- 标记状态：用✅或[x]表示已完成，[ ]表示未完成
