# 软/硬防御技能判别表 v2 —— 防御用途分类（原作全技能过筛）

> v2（2026-10-04 主人批评重做）：v1 两大错误——①"场景防御"类别取消（墙挡球=格挡的场地载体，归硬挡）②软化判得过窄（只认减伤减速，漏了恢复/回避/被动防）。**采用游戏防御分类学**（回避 Avoidance / 格挡 Block / 缓释 Mitigation / 恢复 Recovery——WoW 坦克设计经典四分类+主动/被动轴）。
> **口径**：防御用途=降低来球威胁（硬挡格挡/减伤缓释/降低被命中概率/受击后恢复）。攻击技、资源技、表演技=非防御。
> 来源：docs/原作队伍元灵技能资料_填写版.md；维护=规划窗口初判、主人裁决、新技能验收后追加。

## 分类定义（v2）

| 类别 | 定义 | AI 行为平替 |
|---|---|---|
| **硬挡（格挡）** | 有实体/状态物理性处理来球（挡/拦/反弹/瓦解/消耗战） | 替代跳跃：来球→开挡 |
| **软化（缓释）** | 降低来球伤害或提升生存（防/抗/免/隐） | 替代硬拼：来球→先挂缓释再扛 |
| **回避** | 降低被命中概率（控敌/加速走位/隐身/预警） | 替代固定走位：主动控距/隐身 |
| **恢复** | 受击后恢复（回血/回能/解控） | 支援型防御：事后回血 |
| 非防御 | 攻击/资源/表演 | 不参与防御决策 |
