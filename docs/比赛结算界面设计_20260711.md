## 一、当前现状分析

| 系统 | 状态 | 说明 |
|------|------|------|
| 比赛结束判定 | ✅ 已有 | 团灭或时间到 → `match_ended` 信号 |
| 结束画面UI | ❌ 没有 | 仅打印日志 + 清空食物 |
| 奖励系统 | ❌ 没有 | 无货币/物品/经验获取途径 |
| 装备耐久 | ❌ 没有 | items.json 无 durability 字段 |
| 食物消耗 | ✅ 已有 | 赛前食用，赛后 `clear_active_food()` |
| 个人数据统计 | ❌ 没有 | 仅AI调优用的团队级指标 |

## 二、触发流程设计

```
比赛进行中
  ├─ 时间到（下半场结束）→ match_ended 信号
  └─ 一队全灭 → _check_defeat_condition() → match_ended 信号
        │
        ▼
  1. 冻结全场（所有球员velocity=0, AI暂停, 球停止）
  2. 延迟2秒（让玩家看到最后画面）
  3. 播放过渡动画（淡入黑幕 + "比赛结束"大字）
  4. 弹出结算界面
        │
        ▼
  结算界面（4个Tab页）：
  ┌─────────────────────────────────┐
  │  [胜利/失败横幅 + 比分]          │
  │  [Tab: 战报] [Tab: 数据] [Tab: 奖励] [Tab: 确认]│
  └─────────────────────────────────┘
        │
        ▼ (玩家点击"确认返回")
  5. 执行结算：扣装备耐久、扣食物、发奖励
  6. 返回基地主界面
```

## 四、新增系统设计

### 4.1 装备耐久系统

#### 数据结构变更（items.json 每个装备新增字段）

```json
{
  "id": "eq_glove_rare_01",
  "max_durability": 100,
  "durability_loss_per_match": 5
}
```

#### 存档结构变更（player_save）

```json
"equipment": {
  "equipped": {
    "char_001": {
      "glove": {"item_id": "eq_glove_rare_01", "durability": 95},
      "jersey": {"item_id": "eq_jersey_rare_01", "durability": 90},
      "shoes": {"item_id": "eq_shoes_rare_01", "durability": 85}
    }
  }
}
```

#### 耐久规则设计（确认，最大耐久由快捷设置定）

| 稀有度 | 最大耐久 | 每场损耗 | 属性衰减阈值 |
|--------|---------|---------|-------------|
| common |         |  | <30时属性-50% |
| good |          |  | <40时属性-50% |
| rare |          |  | <50时属性-50% |
| epic |          |  | <60时属性-50% |
| legendary |     |  | <75时属性-50% |
衰减阈值的判断耐久只在开局装备初始判断，对局中不判断


#### 耐久为0时处理


- 装备消失

### 4.3 奖励系统

#### 基础奖励表（确认）

| 结果 | 童话币 | 元灵矿石 | 水晶 | 经验 |
|------|-------|---------|------|------|
| 胜利 | 300 | 10 | 2 | 100 |
| 败北 | 150 | 5 | 1 | 50 |
| 平局 | 200 | 7 | 1 | 75 |



#### MVP判定规则（确认）

优先级排序：
 
1. 击杀数最多
2. 击杀数相同看伤害量
3. 伤害相同看接球次数
4. 存活到最后的球员优先




#### 特殊奖励（确认）

| 条件 | 童话币加成 |
|------|----------|
| 首杀奖励 | +10 |

| 零死亡奖励 | +10 |

### 4.4 个人数据统计系统

#### 新增 `match_player_stats.gd`

在比赛过程中采集每个球员的统计数据：

```gdscript
# 每个球员的统计数据
var stats = {
    "player_id": "char_001",
    "player_name": "小呆呆",
    "team": "a",
    
    # 进攻数据
    "kills": 0,           # 击杀数
    "damage_dealt": 0,    # 总伤害量
    "skill_hits": 0,      # 技能命中次数
    
    # 防守数据
    "deaths": 0,          # 被击杀次数
    "damage_taken": 0,    # 承受伤害
    "balls_caught": 0,    # 接球次数
    "balls_intercepted": 0, # 截球次数
    
    # 辅助数据
    "assists": 0,         # 助攻（3秒内配合击杀）
    
    # 技能数据
    "skills_used": 0,     # 技能释放次数
    
    # 生存数据
    "survived": true,     # 是否存活到最后
    "stamina_remaining": 45, # 剩余体力
    
    # 装备数据
    "equipment_durability_before": {},  # 赛前耐久
    "equipment_durability_after": {},   # 赛后耐久
}
```

#### 数据采集点（埋点位置）

| 事件 | 埋点文件 | 埋点位置 |
|------|---------|---------|
| 死亡/击杀 | `player.gd` | `_on_defeated()` |
| 伤害 | `ball.gd` | `_on_hit_player()` |
| 接球/截球 | `ball.gd` | `_on_caught()` |
| 技能释放 | `input_manager.gd` | `_on_skill_activated()` |
| 技能命中 | `ball.gd` | 技能击中球员时 |
