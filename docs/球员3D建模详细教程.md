# 决竞球 球员3D建模详细教程

> **本文档定位**:从零到可用的球员 3D 素材全流程操作手册(**混元+Mixamo 多工具版,保姆级**)。
> 适用对象:项目主人(**零美术基础、没用过 Blender/Mixamo 也能照着点**)。
> 核心工具链:**腾讯混元3D**(生模型) + **Mixamo**(自动绑骨+动画) + **Blender 5.1.2**(格式转换/减面,已装)。
> 配套代码:`scripts/battle/player.gd` 的 `USE_3D_MODEL` 开关(已实现,见末尾"代码接入"章节)。
> 版本:v5.2(2026-06-21,对齐主人实际环境 Blender 5.1.2,加 4.2+ FBX 插件默认禁用的前置坑)

---

## 〇、TL;DR(太长不看版)

```
① 即梦/通义 生一张 T-pose 参考图(有文字框,控造型)
② 混元3D 图生3D 生模型(下载 GLB)
③ Blender 转 FBX(混元下GLB / Mixamo不吃GLB)
④ Mixamo 上传 FBX → 自动绑骨(标记关节,AI生成骨骼)
⑤ Mixamo 选动作(idle/跑/投/受击) → 下载带骨骼动画的 FBX
        ↓
⑥ Godot 导入 → player_model_3d.tscn 挂载 → 验证
```

**全程不用手动刷权重,不用画骨骼。先做 1 个球员走通,再批量。**

## 一、为什么是混元+Mixamo 多工具(不是混元一站式)

| 工具 | 能做 | 不能做 |
|------|------|--------|
| **混元3D 创作引擎(普通版)** | ✅ 文生/图生3D 生模型 | ❌ **无绑骨/动画入口**(专业版才有,邀请制内测) |
| **Mixamo(Adobe)** | ✅ 自动绑骨 + 海量动画库 | ❌ 不吃 GLB(必须 FBX);⚠️ 2025.6起服务稳定性存疑 |
| Blender | ✅ 格式转换/减面/修原点 | 需手动操作(可选环节) |

**核心结论(2026-06-21 实测确认)**:
- 混元普通版账号(`3d.hunyuan.tencent.com`)**没有绑骨入口**——完整绑骨在"混元3D Studio 专业版",邀请制内测,普通账号进不去
- 所以**混元只负责生模型**,绑骨+动画交给 **Mixamo**(免费、人形角色全覆盖)
- 两工具间用 **Blender 转一次 FBX** 衔接(混元下 GLB,Mixamo 只吃 FBX)

### 弃用方案记录(避免重走弯路)

| 方案 | 弃用原因 |
|------|---------|
| ~~Meshy 一站式~~ | 免费版**导出带骨骼模型受限**,动画预设仅20+ |
| ~~混元一站式~~ | **普通版无绑骨入口**,专业版邀请制内测,不保证能用 |
| ~~腾讯云绑骨API~~ | 要写代码调接口,零美术基础门槛太高 |

## 三、第1步:用 AI 画图工具生 T-pose 参考图

### 为什么必须 T-pose
- **混元图生3D**:T-pose 参考图 = 高质量模型前提
- **Mixamo 自动绑骨**:**硬要求** T-pose 大字型,非 T-pose 绑骨会扭曲

所以参考图**必须**双臂水平张开呈大字型。

### 工具(任选其一,都有文字对话框)
| 工具 | 网址 | 备注 |
|------|------|------|
| 即梦 AI | `https://jimeng.jianying.com/` | 字节,中文友好,免费额度足 |
| 通义万相 | `https://wanx.aliyun.com/` | 阿里,角色一致性好 |
| 豆包·图像生成 | 豆包 App 内 | 免费,最简单 |

### T-pose 参考图关键词(直接复制)
```
Q版卡通小猪足球运动员,T-pose,双臂水平张开呈大字型,
手臂与地面平行,掌心朝下,双腿并拢直立,
全身正面照,纯白背景,平光无阴影,
猪猪侠风格,大头小身,Q版比例,
正面视角,居中构图,高清
```

### 验收参考图
- ✅ 双臂**水平张开**(不是斜向下、不是贴身) ← 最关键,绑骨前提
- ✅ 全身入镜(头顶到脚底都在画面里)
- ✅ 正面视角、纯白背景
- ❌ 手臂贴身 / 半身 / 侧面 → 重新生成,关键词末尾再追加一遍 `T-pose,双臂水平张开`

存放:`建模素材库/2D图片素材/char_001_tpose_ref.png`

## 四、第2步:混元3D 图生3D 生模型

### 4.1 注册混元3D
1. 打开 `https://3d.hunyuan.tencent.com/`
2. 微信扫码登录,**不需要信用卡**
3. 进入控制台

### 4.2 图生3D
1. 点 **"图生3D"**
2. 上传 `char_001_tpose_ref.png`
3. 参数设置:
   - **风格**:选 **"风格化"** / "卡通"(不要选写实 PBR)
   - **多视角**:**开启**(只有正面图时,平台自动补背面/侧面)
4. 点生成(会出多个候选)

### 4.3 选模标准
- ✅ **双臂张开**(T-pose 保持住了)——Mixamo绑骨前提,最关键
- ✅ 整体造型完整(无残肢、无破洞)
- ✅ 面部清晰,造型像 Q版小猪
- ✅ 背面也合理(多视角生效了)
- ❌ 手臂贴身 → 重新生成,确认参考图是 T-pose
- ❌ 手指严重粘连、身体有洞 → 换候选

### 4.4 下载 GLB
- 下载格式选 **GLB**
- 重命名:`char_001_base.glb`
- 放到:`建模素材库/3D图片素材/raw/char_001_base.glb`

**注意**:混元下载页**没有绑骨入口**,这是正常的——绑骨交给下一步的 Mixamo。

## 五、第3步:Blender 转 FBX(Mixamo 不吃 GLB)

> Mixamo 只接受 **FBX/OBJ/ZIP**,混元下载的是 GLB,必须转一次。
> **本文档按 Blender 5.1.x 界面写**(5.0/5.1 通用,4.x 也基本一致)。

### 5.0 前置检查:FBX 插件是否启用(Blender 4.2+ 的重要坑!)

> ⚠️ **Blender 4.2 起,FBX 导入导出插件默认不启用了**,必须手动开。不开的话 File 菜单里**看不到 FBX 选项**。

**检查方法**:
1. 打开 Blender → 顶部菜单 **Edit(编辑)→ Preferences(偏好设置)**
2. 左侧选 **Add-ons(插件)** 或 **Get Extensions(获取扩展)**(5.1 叫法)
3. 搜索框输入 `FBX`
4. 找到 **"Import-Export: FBX format"**(导入导出:FBX 格式)
5. **勾选它前面的方框**(变亮 = 启用)
6. 关闭偏好设置窗口

✅ 启用后,**File → Import / Export 菜单里才会出现 "FBX" 选项**
❌ 如果不勾,你根本找不到导出 FBX 的入口 ← 这是新手第一个大坑

---

### 5.1 打开 Blender + 导入 GLB(一步一步来)

**① 启动 Blender**
- 双击图标 → 弹出启动画面 → 点 **"General"**(通用 / 通用 3D 场景)那个大方块
- 进入主界面,默认有一个立方体 + 摄像机 + 灯

**② 删掉默认立方体**(否则它会一起被导出,污染模型)
- 鼠标在中间 3D 视图点一下(确保焦点在视图里)
- 按键盘 **`A`** 键 → 全选(画面所有物体变橙)
- 按键盘 **`X`** 键 → 弹出确认 → 按 **`D`**(Delete)或回车确认
- 此时视图应该空了(只剩栅格地面)

**③ 导入 GLB**
- 顶部菜单栏点 **"File"**(文件)→ 鼠标移到 **"Import"**(导入)→ 点 **"glTF 2.0 (.glb/.gltf)"**
- 弹出文件浏览窗口 → 找到 `char_001_base.glb` → 双击它 / 选中后点右下角 **"Import glTF 2.0"** 按钮
- 中间视图出现你的模型

> 如果 Import 菜单里**没有 glTF 选项**,同样去 Edit→Preferences→Add-ons 搜 `glTF` 勾上。Blender 一般默认带,5.1 偶尔要手动开。

---

### 5.2 检查模型(确认贴图在、是 T-pose)

**① 看贴图有没有显示出来**
- 默认 Blender 视图是"实体"模式,模型可能是灰的(看不到贴图)
- 顶部右上角有 4 个小圆球图标(视图着色模式)→ 点 **从右数第二个**(带纹理球的"Material Preview / 材质预览")
- 模型应该显示出颜色/贴图了

**② 检查是不是 T-pose**
- 滚轮缩放 / 中键拖动旋转视角,看看模型是不是**双臂水平张开大字型**
- ✅ 是 → 继续
- ❌ 不是(手臂贴身/半身)→ 关掉 Blender,回第1步重新生参考图/生模型

**③ 删除多余节点**(可选,但建议)
- 看右侧 **"Scene Properties / 场景属性"** 或视图里的对象列表
- 如果有"Camera / Light / Cube"等非模型节点(已删空可跳过),选中按 `X` 删掉
- 只留你的角色模型

---

### 5.3 导出 FBX —— **核心步骤,保姆级**

**① 进入导出窗口**
- 顶部菜单 **"File"**(文件)→ **"Export"**(导出)→ **"Filmbox (.fbx)"**
- 弹出导出窗口

> ⚠️ 如果 Export 菜单里**没有 Filmbox/FBX 选项** → 回 5.0 启用 FBX 插件

**② 右侧设置面板**(窗口右边一栏,可能需要往下滚动看全)
导出窗口右侧有一堆折叠选项卡(Include / Transform / Geometry / Armature / Animation)。**按下面顺序设置**:

**【Include 包含】**(默认即可,不用动)
- Limit to:Selected Objects —— **先不勾**(下一步会全选,所以选不选都行)

**【Transform 变换】** —— 重要
- **Scale**:保持 `1.00`(别改)
- **Forward**:选 **`-Z Forward`**(Blender 默认,Godot/Mixamo 都吃)
- **Up**:选 **`Y Up`** ← 关键(游戏引擎标准)
- **Apply Unit Scale**:**勾上**
- **Apply Transform**:**不勾**

**【Geometry 几何体】**(展开,默认值即可,不用动)

**【Armature 骨骼】**(展开,默认值即可,此步还没绑骨,影响不大)

**【Animation 动画】** —— **全部取消勾选**(此时只有模型没动画,动画在 Mixamo 做完再下)
- ❌ **Bake Animation** —— 不勾
- ❌ Key All Bones / Force Start/End Keying —— 不勾

**【⚠️ Path Options 路径选项】** —— **最关键的一步,贴图嵌入靠它**
> 这一项藏得最深,在右侧选项卡**最下方**,可能要一直滚到底

- 找到 **Path Mode**(路径模式)下拉框 → 默认是 `Auto` → **改成 `Copy`**
  - ⚠️ **必须先改成 Copy**,下一步的按钮才会激活
- Path Mode 右边有个**小图标按钮**(一个**盒子/文件夹**样子的图标)→ **点它一下,让它变成激活状态**(图标会变亮/变蓝)
  - 这个图标就是 **"Embed Textures"(嵌入贴图)**
  - 鼠标悬停它,tooltip 会显示 "Embed Textures"

界面示意(导出窗口右侧从上到下):
```
Include
├─ [ ] Limit to Selected Objects
└─ Selected Only: □
Transform
├─ Scale: 1.00
├─ Forward: -Z Forward
├─ Up: Y Up          ← 关键
├─ [x] Apply Unit Scale
└─ [ ] Apply Transform
Geometry
└─ (默认)
Armature
└─ (默认)
Animation
└─ [ ] Bake Animation   ← 全关
Path Options             ← 滚到最底
├─ Path Mode: [Copy ▼]  ← 改 Copy
└─ [📦 active]          ← 点亮这个图标 = Embed Textures
```

**③ 选保存位置 + 文件名**
- 导出窗口左侧导航到 `建模素材库/3D图片素材/fbx/`(没有这个文件夹就用 Windows 资源管理器先建一个)
- 底部文件名输入框填:`char_001_base`
- 格式确认是 `.fbx`

**④ 点导出**
- 右下角蓝色按钮 **"Export Filmbox"** → 完成
- 去文件夹看一下,应该有个 `char_001_base.fbx`,**文件大小比原 GLB 大一点**(因为嵌入了贴图)

---

### 5.4 自检:FBX 是否成功带贴图

最简单的验证:把生成的 `char_001_base.fbx` **复制一份到别的空文件夹**,双击看能不能打开/拖回 Blender 看。
- ✅ 在新文件夹打开贴图还在 → 嵌入成功,贴图跟着 fbx 走
- ❌ 贴图变灰/丢失 → 回 5.3 重做,确认 Path Mode = Copy 且 Embed 图标已点亮

### 5.5 命名与存放
- 最终文件:`建模素材库/3D图片素材/fbx/char_001_base.fbx`
- 这个文件下一步上传 Mixamo

## 六、第4步:Mixamo 自动绑骨

### 6.1 注册 Mixamo(第一次用要做)
1. 浏览器打开 `https://www.mixamo.com`
2. 右上角点 **"Log In / Sign Up"** → 跳到 Adobe 登录页
3. 用 **Adobe 账号**登录
   - 有 Adobe 账号直接登
   - 没有就点 **"Create an account"** 注册一个(免费,填邮箱即可,不需要信用卡)
4. 登录成功后自动跳回 Mixamo,顶部能看到你的用户名

⚠️ 若登录失败/页面转圈/报错 → 看 11 章踩坑表(Mixamo 2025.6起服务稳定性存疑),或切备选 AccuRIG

---

### 6.2 上传模型(一步一步来)

**① 找到上传按钮**
- 进入 Mixamo 主页后,默认在 **"Characters"(角色)** 标签页
- 中间或左上有 **"Upload Character"**(上传角色)按钮(蓝色)→ 点它

**② 选文件**
- 弹出文件选择框 → 找到 `char_001_base.fbx`(上一步 Blender 导出的)
- 选中 → 打开
- 开始上传(看底部进度条,几秒到几十秒)

**③ 等待检测**
- 上传完 Mixamo 自动分析模型
- 如果模型是 T-pose,会自动识别成功,进入下一步标记界面
- 如果弹窗提示姿态问题 → 模型可能不是标准 T-pose,回第1步重做参考图

---

### 6.3 标记关节点(Auto Rigger)—— **保姆级 + 对称设计说明**

上传成功后,进入**标记界面**。画面里:
- 你的模型站在中间
- 模型身上有 **9 个黄色圆点(marker)**

**⚠️ 关键认知:Mixamo 用"对称标记"设计**
- 你只标**半边身体**(比如只标左半边或右半边)
- Mixamo **自动镜像**到另一半(9×2 = 18 关节全覆盖)
- 所以只看到 9 个点是正常的,**不是 bug**

---

**需要标记的 9 个点**(以半边为例):

| # | 部位 | 怎么找 |
|---|------|--------|
| 1 | **下巴** | 下巴尖正中(中线位置) |
| 2 | **裆部/盆骨** | 两腿正中间上方(中线位置) |
| 3 | **肩膀**(单侧) | 脖子根和肩膀连接处 |
| 4 | **手肘**(单侧) | 手臂中段弯曲处 |
| 5 | **手腕**(单侧) | 手掌根部 |
| 6 | **膝盖**(单侧) | 大腿小腿连接处 |
| 7 | **脚踝**(单侧) | 小腿和脚连接处 |
| 8-9 | 其余辅助点 | 看界面提示,可能是脚尖/指尖等 |

> 具体哪 9 个,看 Mixamo 界面上黄点的初始位置,按 tooltip 提示标。

---

**⚠️ 操作姿势(关键!"拖出来就没了"的根因)**

Mixamo 黄点是**吸附式**的,必须拖到模型表面:

| 操作 | 结果 |
|------|------|
| ✅ 左键按住黄点 → **拖到模型皮肤上** → 松手 | 点吸附住,成功定位 |
| ❌ 左键按住黄点 → **拖到模型外/空中** → 松手 | **点消失**(你遇到的) |
| ❌ 拖到位置松手太快/没贴稳 | 点可能弹回原位 |

**正确姿势分步**:
1. 鼠标**左键按住**一个黄点(不要松)
2. **慢慢拖动**到对应关节位置
3. 拖到**模型表面贴着皮肤**(能看到点贴在模型上,不是悬空)
4. **松开左键**
5. 黄点应该吸附在新位置(变绿/变亮 = 确认)

---

**辅助技巧**:
- **滚轮缩放** + **中键拖动旋转视角**,从不同角度确认点贴准了
- 标完所有点后,右下角点 **"Next"(下一步)**
- 如果拖错位置,重新拖一次即可(不需要重置)
- 如果点消失了,**刷新页面重新上传**,小心这次别拖出模型外

---

**标记要点**:
- ✅ 黄点必须**贴在模型表面**(皮肤上)
- ✅ 左右对称的关节,只标一侧就行(另一侧自动镜像)
- ✅ 中线点(下巴/裆部)标在正中
- ❌ 不要把点拖到模型外的空气里(会消失)

---

### 6.4 生成骨骼

- 点完 Next 后,Mixamo 让你**选手指骨骼精细度**
  - 默认 **"2-chain fingers"(2段手指)** 够用 → 直接选这个
  - 高级选 "3-chain" 但没必要
- 点 **"Process / Rig"(处理/绑骨)** 蓝色按钮
- 等待云端处理(几秒到几十秒)
- 完成后画面显示带骨骼的角色(半透明的骨架叠加在模型上)

---

### 6.5 验证绑骨

Mixamo 处理完会自动给你**预览一个动作**(通常是挥手或 idle)。

**重点检查**:
- ✅ 角色动作时关节弯曲方向正常(手肘朝后弯、膝盖朝前弯)
- ✅ 没有穿模(手脚穿透身体)
- ✅ 骨骼位置合理(骨架和模型对齐)

❌ **如果扭曲严重**:
- 原因 A:6.3 的关节点标错了位置 → 点 **"Re-rig"(重新绑)** 回去重标
- 原因 B:模型不是标准 T-pose → 关掉 Mixamo,回第1步重做参考图

**绑定成功后,Mixamo 会把这个角色存到你的账号**,下次直接在 Characters 列表选它,不用重复上传。

---

## 七、第5步:Mixamo 选动作(idle/跑/投/受击)—— **保姆级**

### 7.1 进入动画库

- 绑骨完成后,左侧菜单点 **"Animations"(动画)** 标签
- 中间区域出现一个搜索框 + 大量动画缩略图
- 右上角确认"当前角色"是你刚绑的那个(头像在右上角)

### 7.2 找这 4 个动作

**怎么搜**:
- 中间搜索框输入英文关键词,下面会刷出匹配的动画
- 每个动画有缩略图 + 名字 + 鼠标悬停会自动预览播放

| 项目动作 | 搜索关键词 | 挑哪个 |
|---------|-----------|--------|
| idle | `idle` / `breathing` | "Idle" 或 "Breathing Idle"(呼吸待机,循环) |
| 奔跑 | `run` / `jog` | "Jog" 或 "Run"(跑步,循环) |
| 投球 | `throw` / `toss` | "Throw"(投掷,单次) |
| 受击 | `hurt` / `stumble` / `fall back` | "Stumble" 或 "Falling back"(踉跄/倒地,单次) |

**挑动画的要点**:
- ✅ 动作幅度适中(不要夸张的舞蹈/格斗)
- ✅ 循环动作(idle/run)鼠标悬停时会**无缝循环**(动作结尾接到开头)
- ❌ 动作里角色自带位移(一直往前走) → 下载时必须勾 in place(见 7.3)

---

### 7.3 下载一个动作 —— **核心步骤,界面选项详解**

**点中一个动画后**,右侧出现**下载设置面板**(Download 区域)。**按下面设置**:

**① 鼠标点中想下载的动画**(缩略图点一下,变成选中状态,右侧面板激活)

**② 右侧 Download 设置**(从上到下):

| 选项 | 选什么 | 为什么 |
|------|--------|--------|
| **Format(格式)** | **FBX for Unity (.fbx)** | Godot 吃 Unity 格式,兼容最好。别选 Binary/UE |
| **Include Skin(带不带模型)** | **✅ 勾上**(每动作下第一次都带模型) | 带网格一起下,Godot 才能看到角色。第二次下同类动作可不带 |
| **Skin**(皮肤) | 选你的角色 | 默认就是当前角色 |
| **Frames per Second(帧率)** | **30** | 游戏标准帧率 |
| **Keyframe Reduction(关键帧精简)** | 默认(None / Constant) | 不用动 |
| **⚠️ In Place(原地)** | **✅ 必勾** | 角色原地播放不位移,否则导入 Godot 角色会自己往前走 |
| **Mixed Time**(混合时间) | 不勾 | 单次动作可不勾 |

**界面示意(右侧下载面板)**:
```
┌─ Download ─────────────┐
│ Format: [FBX for Unity ▼]   ← 选这个
│ ───────────────────────
│ [x] Include Skin            ← 勾上(第一次下必勾)
│      Skin: [My Character ▼]
│ ───────────────────────
│ Frames per Second: [30 ▼]
│ ───────────────────────
│ [x] In Place                 ← 必勾!原地动画
│ [ ] Mixed Time
└──────────────────────────┘

         [蓝色 Download 按钮]   ← 设置完点这个下
```

**③ 点 Download 蓝色按钮**
- 浏览器下载文件,得到一个 .fbx(或 .zip 解压出 .fbx)

**④ 重命名 + 存放**
- 重命名为 `char_001_idle.fbx`
- 放到 `建模素材库/3D图片素材/anim/char_001_idle.fbx`

### 7.4 重复下载其余 3 个动作

对 run / throw / hurt **各重复一遍 7.3**:
- 搜关键词 → 选动画 → 右侧设置(Format=FBX Unity, In Place勾) → Download → 重命名存放

最终得到 4 个文件:
- `char_001_idle.fbx`
- `char_001_run.fbx`
- `char_001_throw.fbx`
- `char_001_hurt.fbx`

### 7.5 8方向怎么处理(省8倍工作量)
- **只做 1 套奔跑动画**,8方向靠 Godot 里旋转角色朝向(`rotation.y`)实现
- 不需要做 8 套不同方向的动画
- 实际只需 **4 套动画**:idle / run / throw / hurt

## 八、第6步:Godot 导入与合并动画

### 8.1 拖入项目
1. 4 个 fbx 复制到 `assets/characters/avatars/`
2. Godot 编辑器自动生成 `.import` 文件
3. FileSystem 面板确认 fbx 显示为 PackedScene 图标

### 8.2 双击任一 fbx 预览检查
1. 双击 `char_001_idle.fbx` → 打开场景
2. 检查:
   - ✅ 模型显示正常(贴图、颜色对)
   - ✅ 有 `Skeleton3D` / `Armature` 节点
   - ✅ 有 `AnimationPlayer` 节点,里面有 1 个动画
3. 其他 3 个 fbx 同样检查

### 8.3 合并 4 个动画到一个模型(推荐做法)
Mixamo 每个动作下出来都是**独立 fbx**(模型重复4份)。Godot 里建议合并:
1. 以 `char_001_idle.fbx` 为主场景
2. 把 run/throw/hurt 的动画**复制到主场景的 AnimationPlayer**(或用 AnimationLibrary 管理)
3. 详细合并脚本可用 Godot 的 `AnimationLibrary.add_animation()`,或导入时让 Godot 自动 retarget

> 这一步第一次做会卡,试点时主人遇到问题随时问我,不要硬扛。

### 8.4 常见问题排查

| 现象 | 原因 | 解决 |
|------|------|------|
| 模型全黑 | FBX 导出没嵌入贴图 | 回第3步 Blender 勾 Embed textures |
| 没有 AnimationPlayer | Mixamo 下载没勾 Include Skin | 回第5步重下 |
| 动画列表为空 | 动作没套上 | 回第4步在 Mixamo 重新套 |
| 手脚扭曲 | 绑骨定位点标错 / 非 T-pose | 回第4步重绑 |
| 角色自己往前走 | 没勾 in place | 回第5步 Mixamo 勾 in place 重下 |
| 模型飞天上 | 原点不在脚底 | 见附录B(Blender 修原点) |

## 十一、踩坑速查表

| 问题 | 阶段 | 解决 |
|------|------|------|
| 混元找不到绑骨入口 | 混元 | **正常,普通版没有**。绑骨交给 Mixamo |
| 参考图手臂贴身 | 生图 | 关键词追加 `T-pose,双臂水平张开`,重生成 |
| 图生3D出来手臂贴身 | 生模型 | 参考图不是 T-pose,回第1步 |
| Blender 转 FBX 贴图丢 | 转格式 | 导出勾 **Embed textures** + Path Mode: Copy |
| Mixamo 上传失败 | Mixamo | 确认是 FBX/OBJ/ZIP,不是 GLB |
| Mixamo 登录失败 | Mixamo | 2025.6起服务不稳,清缓存重试,或切 AccuRIG(附录C) |
| Mixamo 绑骨扭曲 | Mixamo | 定位点标错或非 T-pose,重上传重标 |
| Mixamo 黄点拖出消失 | Mixamo | 必须拖到**模型表面贴皮肤**,不能拖到空中/模型外(详见 6.3) |
| 动画下完角色往前走 | Mixamo | 下载前勾 **in place**(原地) |
| 导出文件没动画 | Mixamo | 下载勾 Include Skin |
| Godot 里模型全黑 | 导入 | FBX 没嵌入贴图,回 Blender 重导 |
| 12球员同屏卡顿 | 集成 | 模型太大,用附录A减面 |
| AI行为变了 | 验证 | 检查是否误改物理/碰撞代码(本次改造没碰) |

## 附录A:可选 —— Blender 减面(仅文件太大时用)

> 只有当 fbx > 15MB 或 12 球员同屏卡顿时才需要。新手先跳过。

1. Blender 导入模型
2. 选中模型 → Modifier Properties → Add → **Decimate**
3. Ratio 设 0.1-0.3,目标 < 8000 三角面
4. Apply
5. 导出 FBX

## 附录B:可选 —— Blender 修原点(模型飞天上时用)

1. Blender 导入
2. 选中模型 → 把 3D 游标移到脚底
3. 菜单 Object → Set Origin → Origin to 3D Cursor
4. 导出
