## 一、定位：统筹层，不是固定职位模板

技能AI是**一个统筹系统**，根据具体球员+元灵组合生成个性化决策模板。

```
赛前 → 读取球员属性 + 元灵技能 → 生成个性化模板
赛中 → 按模板 + 实时局势 → 评分 → 选最高分技能释放
```

**核心区别**：不是"辅助手就该回血"，而是"这个辅助手带了什么技能、身板脆不脆、缺什么"。

## 二、六大设计原则（+复合技能处理）

| 原则 | 核心要点 | 关键修正 |
|------|---------|---------|
| 1. 效用驱动 | 评分制决策，选最高分释放 | 引入**技能意图**维度（进攻/防御/支援） |
| 2. 角色视角差异化 | 同一技能不同角色看到不同意图 | 主攻手不是"不爱给自己buff"，是"评估一切技能的进攻价值" |
| 3. 局势敏感 | 评分受球权/分差/体力/时间/人数/进攻窗口影响 | 球权因子改为**连续梯度**，不再二值化 |
| 4. 动态资源管理 | 动态比较"现在用的价值"vs"留到未来" | 取消固定三档阈值，改为**机会成本评估** |
| 5. 技能意图适配 | 同一类型技能有多种意图用法 | FIELD技能也能进攻用（挡住防守路线=创造空间） |
| 6. 数值外置 | 所有参数在AIProfile中 | 19个可调参数 |
| **7. 复合技能处理** | 一个技能可含多个标签（球+球员+场） | 按多标签权重综合评估，不强行归类到单一标签 |

## 二点五、复合技能处理规则

### 数据格式
- 单标签（兼容）：`"tag": "on_ball"`
- 多标签（新格式）：`"tag": ["on_ball", "on_player"]`

### 权重规则

| 标签数 | 权重 | 解释 |
|--------|------|------|
| 1个 | 100% | 纯单标签技能 |
| 2个 | 各70% | 双标签复合 |
| 3个 | 各50% | 三标签复合 |

### 应用到评估项

| 评估项 | 单标签处理 | 多标签处理 |
|--------|----------|----------|
| **基础价值 base_value** | 直接按该标签算 | 各标签价值×权重求和 |
| **意图分布 intents** | 单一意图 | 各标签意图×权重叠加 |
| **使用时机** | 按主标签 | 全标签独立判断 |
| **目标选择** | 按主标签 | 主标签选目标 |
| **协同度** | 与属性匹配 | 各标签取最高 |

## 三、核心公式

### 3.1 总评分

```
total_score = base_value × situation_factor × intent_match × difficulty_modifier
```

### 3.2 局势综合因子

```
situation_factor = (possession × score_diff × stamina × time × numbers) ^ (1 / reading_depth)
```

- reading_depth 随难度变化：低难度只看1-2个因子，高难度综合判断

### 3.3 意图匹配度（取代旧版role_preference）

```
intent_match = intent_weight(role, skill_intent) × situation_intent_bonus
```

| 角色 | 进攻意图 | 防御意图 | 支援意图 |
|------|---------|---------|---------|
| 主攻手 | 1.4 | 0.9 | 1.0 |
| 防御手 | 0.9 | 1.4 | 1.0 |
| 辅助手 | 1.0 | 1.0 | 1.4 |

> 最低权重0.9，不是极端低——角色不是"不会某类技能"，只是"评估重心不同"。

### 3.4 动态能量评估（取代旧版固定阈值）

```
energy_value_now = total_score
energy_value_future = expected_future_score × time_remaining × uncertainty_discount

should_use = energy_value_now > energy_value_future × reserve_weight × situation_modifier
```

| 角色 | reserve_weight | 风格 |
|------|---------------|------|
| 主攻手 | 0.7 | 机会型——进攻窗口稍纵即逝 |
| 防御手 | 1.1 | 预判型——等对方进攻精准反制 |
| 辅助手 | 0.9 | 响应型——根据队友缺口调整 |

### 3.5 球权因子（连续梯度）

```
possession_factor = lerp(defense_value, attack_value, ball_possession)
```

不再是我方持球=1.5/0.5的二值判断，而是0~1连续梯度。

## 四、段位难度系统

### 难度映射

| 段位 | 难度等级 | 定位 |
|------|---------|------|
| 青铜 | 1-2 | 入门 |
| 白银 | 3-4 | 普通 |
| 黄金 | 5-6 | 中等 |
| 铂金 | 7-8 | 进阶 |
| 钻石 | 9 | 高手 |
| 王者 | 10 | 顶尖 |

### 缩放公式

```
normalized = (difficulty - 1) / 9    # [0, 1]
实际值 = base × (1 + (normalized - 0.5) × 2 × scale_range)
最终值 = clamp(实际值, min, max)
```

### 关键参数

| 参数 | 难度5基准 | 难度1 | 难度10 |
|------|----------|-------|--------|
| skill_use_threshold | 40 | 56(犹豫) | 24(敢用) |
| skill_mistake_chance | 0.15 | 0.3(常失误) | 0(零失误) |
| situation_reading_depth | 3 | 1(片面) | 6(全面) |

## 五、赛前个性化分析

### 5.1 分析输入

| 数据源 | 关键字段 |
|--------|---------|
| 球员数据 | attack/defense/speed/stamina/resilience/ball_speed/talent |
| 元灵技能 | tags/energy_cost/cooldown/tag_params/element |

### 5.2 球员弱点/强项判定

```
risk_score = (1-def)×0.3 + (1-sta)×0.3 + (1-res)×0.2 + (1-spd)×0.2

> 0.6 → high risk（需频繁防御/恢复）
> 0.3 → medium
≤ 0.3 → low（可激进进攻）
```

### 5.3 技能协同度

```
synergy = 弥补弱点(+0.4~0.6) + 强化强项(+0.3) + 能量适配(±0.1)

≥ 0.8 → critical（关键技能，必须优先）
≥ 0.5 → high
≥ 0.2 → medium
< 0.2 → low
```

### 5.4 实战示例

| 球员+元灵 | 弱点 | 协同判定 | 策略调整 |
|-----------|------|---------|---------|
| 菲菲+草木 | 防御低/体力低 | 防御buff=critical | 能量阈值降到15，reserve_weight=0.8 |
| 菲菲+梦幻 | 防御低/体力低 | 隐身=critical(唯一保命) | 血量<30%立即隐身，reserve_weight=0.7 |
| 超人强+大地 | 无明显弱点 | 岩石墙=high | reserve_weight=1.1，可攒能量 |

## 六、技能标签深度分析

### 6.1 标签效果分类

| 大类 | 示例标签 |
|------|---------|
| 伤害 | ball_dmg_up_pct, player_hp_damage_flat |
| 恢复 | player_hp_heal_flat, player_hp_regen |
| 增益 | player_atk_up_pct, player_def_up_pct |
| 减益 | player_atk_down_pct, player_move_slow |
| 控制 | player_stun, player_root |
| 免疫 | player_cc_immune, player_invincible |
| 场地 | field_obs_add, field_speed_zone |

### 6.2 深度分析维度

每个标签分析：副作用、叠加性、克制关系、协同标签、利弊比。

### 6.3 组合类型

| 类型 | 示例 |
|------|------|
| 连招 | 减速→眩晕→高伤害球（+48%效果） |
| 互补 | 回血+防御buff（草木技能本身） |
| 协同 | 加速+隐身（梦幻技能） |
| 应急 | 无敌+传送（保命组合） |

### 6.4 元素克制

克制+30%，被克制-30%。

## 七、球员属性感知

### 7.1 队友感知

```
支援目标评分 = 治疗需求×0.4 + 防御需求×0.3 + 威胁等级×0.2 + 距离×0.1
```

### 7.2 敌人感知

```
攻击目标评分 = 威胁程度×0.3 + 血量低×0.3 + 抗性匹配×0.2 + 能量低×0.1 + 距离×0.1
```

### 7.3 团队短板

团队平均属性低于阈值时，对应类型技能全局加成+0.2。

## 八、完整决策流程

```
赛前：
  读取球员+元灵 → 球员弱点分析 → 技能深度分析（tags归一化）→ 协同度计算
  → 生成个性化模板 → 团队评估 → 调整全局权重

赛中（每0.5秒）：
  检查能量 → 获取可用技能 → 感知队友/敌人状态
  → 对每个技能：
      tag 归一化（字符串/数组）→ 主标签判定 → 按多标签权重分别计算
      → 基础价值（加权求和）→ 意图分布（加权叠加）
      × 局势因子 × 意图匹配 × 协同度 × 元素克制
      → 动态能量评估
  → 考虑组合策略 → 选最高分 → 达阈值则释放
```
