## 三、核心文件：`skill_vfx_config.json`（你日常编辑的唯一文件）

这是 **「特效配方」**，每条技能对应一份，格式如下：

```json
{
  "vfx_configs": [
    {
      "skill_id": "skill_雷火_1",
      "element": "雷火",
      "phases": [
        {
          "phase": "cast",
          "vfx_type": "cast",
          "pack": "BinbunVFX_Vol2",
          "effect": "fire_cast",
          "override_colors": true,
          "scale": 1.3,
          "duration_override": 0.6,
          "attach_to": "caster",
          "offset_y": 50
        },
        {
          "phase": "projectile",
          "vfx_type": "projectile",
          "pack": "BinbunVFX_Vol2",
          "effect": "fire_projectile",
          "override_colors": true,
          "scale": 1.0,
          "attach_to": "ball",
          "offset_y": 0
        },
        {
          "phase": "impact",
          "vfx_type": "area",
          "pack": "BinbunVFX_Vol2",
          "effect": "fire_area",
          "override_colors": true,
          "scale": 2.0,
          "radius_override": 120,
          "duration_override": 1.5,
          "attach_to": "impact_point",
          "offset_y": 0
        }
      ],
      "sound": {
        "cast_sfx": "res://assets/audio/fire_cast.ogg",
        "impact_sfx": "res://assets/audio/fire_impact.ogg"
      }
    },
    {
      "skill_id": "skill_冰雪_1",
      "element": "冰雪",
      "phases": [
        {
          "phase": "cast",
          "vfx_type": "cast",
          "pack": "BinbunVFX_Vol2",
          "effect": "fire_cast",
          "override_colors": true,
          "scale": 1.0,
          "attach_to": "caster",
          "offset_y": 50
        },
        {
          "phase": "projectile",
          "vfx_type": "projectile",
          "pack": "BinbunVFX_Vol2",
          "effect": "fire_projectile",
          "override_colors": true,
          "scale": 0.8,
          "attach_to": "ball",
          "offset_y": 0
        }
      ],
      "sound": {
        "cast_sfx": "res://assets/audio/ice_cast.ogg",
        "impact_sfx": ""
      }
    }
  ]
}
```

### 配方字段说明

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `skill_id` | string | 与 skills.json 的 id 一致 | `"skill_雷火_1"` |
| `element` | string | 元素名，自动映射配色 | `"雷火"` → `Color(1.0, 0.4, 0.2)` |
| `phases` | array | 技能的视觉阶段序列 | 见下方 |
| **phase 内** | | | |
| `phase` | string | 阶段名：`cast`/`projectile`/`impact`/`linger`/`aura` | `"cast"` |
| `vfx_type` | string | Binbun特效类型：`cast`/`projectile`/`area` | `"area"` |
| `pack` | string | 特效包名（未来可扩展） | `"BinbunVFX_Vol2"` |
| `effect` | string | 包内具体效果名 | `"fire_cast"` |
| `override_colors` | bool | 是否用元素色覆盖默认火焰色 | `true`（冰就用冰色） |
| `scale` | float | 整体缩放倍率 | `1.3` |
| `duration_override` | float|null | 覆盖默认持续时间(秒) | `0.6` |
| `radius_override` | float|null | 覆盖Area半径(Godot单位) | `120` |
| `attach_to` | string | 特效挂载到哪个节点 | `"caster"`/`"ball"`/`"impact_point"`/`"field_zone"` |
| `offset_y` | float | 3D空间高度偏移 | `50`(脚→胸的高度) |

### 阶段(phase)映射规则

技能的**行为标签**决定需要哪些**视觉阶段**：

| 行为标签类型 | target_type | 视觉阶段 | 示例 |
|-------------|------------|---------|------|
| BALL类(数值/飞行) | ball | cast → projectile → impact | 雷霆投掷 |
| FIELD类(障碍/区域) | field | cast → linger(场地上持续) | 岩石墙 |
| PLAYER类(属性/状态) | player | cast → aura(球员身上的持续光环) | 生机护体 |

## 四、代码层：AI搭建，你不改

### 4.1 `SkillVFXPlayer.gd` — 特效播放器（核心）

```
职责：读取 skill_vfx_config.json → 按 skill_id 查配方 → 实例化3D特效 → 挂到目标节点
位置：scripts/systems/spirit_system/skill_vfx_player.gd
调用时机：spirit_skill_trigger.trigger_skill() 成功后，自动调用
```

**工作流**：
1. `trigger_skill()` 成功 → 发信号 `skill_triggered`
2. `SkillVFXPlayer` 收到信号 → 查 `_vfx_configs[skill_id]`
3. 按 `phases[]` 顺序，逐 phase 实例化 Binbun 特效节点
4. 如果 `override_colors=true`，从 `ElementColorBank` 取配色，设到 Binbun 节点
5. 按标签的 `target_type` 确定挂载位置（caster/ball/field_point）

### 4.2 `ElementColorBank.gd` — 元素配色中心

统一所有元素→Binbun三色(primary/secondary/tertiary)的映射：

```gdscript
# 6元素的Binbun配色表（直接照抄保姆指南的配色表）
const ELEMENT_COLORS: Dictionary = {
    "金刚": { "primary": Color(0.85, 0.75, 0.3), "secondary": Color(0.65, 0.55, 0.2), "tertiary": Color(0.35, 0.25, 0.1) },
    "大地": { "primary": Color(0.7, 0.55, 0.35), "secondary": Color(0.55, 0.35, 0.2), "tertiary": Color(0.3, 0.15, 0.05) },
    "雷火": { "primary": Color(1.0, 0.8, 0.2),  "secondary": Color(1.0, 0.4, 0.1),  "tertiary": Color(0.6, 0.1, 0.05) },
    "冰雪": { "primary": Color(0.5, 0.9, 1.0),  "secondary": Color(0.3, 0.6, 0.9),  "tertiary": Color(0.1, 0.3, 0.6) },
    "草木": { "primary": Color(0.3, 0.8, 0.3),  "secondary": Color(0.2, 0.6, 0.15), "tertiary": Color(0.1, 0.3, 0.05) },
    "梦幻": { "primary": Color(0.7, 0.5, 0.9),  "secondary": Color(0.5, 0.3, 0.7),  "tertiary": Color(0.3, 0.15, 0.4) },
}
```

**一处改色，全局生效**——不再需要在5个不同文件里重复定义 `_get_element_color()`。

### 4.3 `VFXEffectRegistry.gd` — 特效包注册表

管理所有已导入的特效包和它们内部的效果路径：

```gdscript
# 特效包注册表
const VFX_PACKS: Dictionary = {
    "BinbunVFX_Vol2": {
        "cast":     "res://assets/BinbunVFX_Vol2/ElementalMagicFX/effects/cast/vfx_fire_cast_01.tscn",
        "projectile": "res://assets/BinbunVFX_Vol2/ElementalMagicFX/effects/projectile/vfx_fire_projectile_01.tscn",
        "area":     "res://assets/BinbunVFX_Vol2/ElementalMagicFX/effects/area/vfx_fire_area_01.tscn",
    },
    # 未来扩展：
    # "BinbunVFX_Vol3": {
    #     "shield": "...",
    #     "lightning": "...",
    # },
}
```

新增特效包时，AI 只需在此注册路径，配方文件即可引用。

### 4.4 `SkillVFXTest.gd` — 专属测试场

**独立测试场景**，你不需要改代码，只需：

1. 打开 `scenes/test/skill_vfx_test.tscn`（F6运行）
2. 左侧面板：下拉选 `skill_id`
3. 右侧3D场地：立即看到该技能的完整3D特效组合
4. 按 `T` 键：重播特效
5. 按 `E` 键：切换元素配色（快速看冰→火→草等换皮效果）

测试场同时显示：
- 2D场地（当前的色块球员）
- 3D覆盖层（大相机SubViewport里的3D特效）

## 五、你的日常操作流程（零代码）

### 5.1 新建技能 + 配特效

```
步骤1：在 skills.json 里添加技能（标签+参数）
        ↓ 你已有此流程（dev_spirit_panel 或手动改JSON）

步骤2：在 skill_vfx_config.json 里添加配方
        ↓ 只需填 skill_id、选phase、选vfx_type、设scale

步骤3：打开 skill_vfx_test.tscn → 选skill_id → F6运行
        ↓ 看效果，不满意就改配方里的 scale/duration/offset

步骤4：满意后，配方自动生效（实战时 SkillVFXPlayer 读同一份JSON）
```

### 5.2 快速换元素配色（改1行JSON）

冰霜技能想用"火系投射物模型但冰色"？配方里只需要：

```json
{
  "skill_id": "skill_冰雪_1",
  "element": "冰雪",
  "override_colors": true   ← 开这个，自动用冰雪色替换火焰色
}
```

**不用改任何 .gd 或 .tscn**，颜色从 `ElementColorBank` 自动映射。

### 5.3 新增特效包（AI做，你验证）

当导入新的 Binbun3D 包（如闪电/护盾/烟雾）时：

1. AI 将包放入 `assets/新包名/`
2. AI 在 `VFXEffectRegistry.gd` 注册路径
3. AI 在 Binbun3D 特效节点根挂脚本（修复之前 projectile 漏挂的问题）
4. 你在配方 JSON 里直接用 `"pack": "新包名"` 即可引用

## 六、实战接入点（现有代码改动最小化）

### 6.1 现有调用链（不改）

```
player按键 → skill_state_manager → spirit_skill_trigger.trigger_skill()
    → spirit_tag_effect_handler.apply_tag_effect()  ← 行为层
    → skill_triggered 信号                            ← 视觉层入口
```

### 6.2 新增接入（仅加1个节点+1行代码）

在 `battle_manager.gd` 的 `setup()` 中：

```gdscript
# 新增：特效播放器
var vfx_player: Node  # SkillVFXPlayer

func setup():
    ...
    # 现有：skill_visual_manager（2D轮廓）
    # 新增：vfx_player（3D特效）
    vfx_player = SkillVFXPlayer.new()
    vfx_player.name = "SkillVFXPlayer"
    add_child(vfx_player)
    # 连接信号
    spirit_system.skill_used.connect(vfx_player._on_skill_used)
```

**就这么一行**。`SkillVFXPlayer` 内部读JSON、实例化Binbun、挂到球员/球/场地节点，全自动。

### 6.3 2D轮廓 → 3D特效的过渡策略

| 当前 | 未来 | 过渡方式 |
|------|------|---------|
| `skill_visual_manager.gd` 渲染2D色环 | `SkillVFXPlayer.gd` 渲染3D特效 | **并存**：2D轮廓给没有3D视角的玩家，3D特效给大相机视角 |
| 色环=元素色半透明 | Binbun3D全特效 | 同一 `ElementColorBank` 配色源，视觉一致 |

**不删除现有2D轮廓系统**——它给纯2D模式下仍然有用。

    { "phase": "cast",   "vfx_type": "cast",     "pack": "BinbunVFX_Vol2", "effect": "fire_cast", "override_colors": true },

## 十一、常见问题

**Q: 2D和3D特效会冲突吗？**
A: 不会。2D轮廓在 `CanvasItem` 层渲染，3D特效在 `SubViewport` 层渲染，互不遮挡。同一技能可以同时有2D轮廓（纯2D玩家看）和3D特效（大相机视角看）。

**Q: 性能如何？**
A: Binbun3D是GPUParticles3D，单次特效约30-50个粒子，6人同场最多同时6个特效 → 约300粒子，对现代设备完全没问题。

**Q: 没有3D场景时特效怎么办？**
A: `SkillVFXPlayer` 检测当前是否有 `SubViewport` + `Camera3D`，没有时自动fallback到现有2D轮廓系统（`skill_visual_manager`），**零改动过渡**。

**Q: 未来换特效包麻烦吗？**
