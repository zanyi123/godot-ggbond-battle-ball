# 段位规划表

---

| 段位 | 名称 | 等级范围 | 对应难度 | 解锁内容 |
|------|------|---------|---------|---------|
| 1 | 业余比赛 | Lv.1-10 | 1-2 | 初始3球员（小呆呆/卜三/迷糊老师），基础装备 |

| 3 | 行星联赛 | Lv.26-45 | 5-6 | 解锁第6球员，高级装备，中级元灵 |

## 二、段位规则

### 2.1 升级规则

| 段位 | 升级所需经验 | 单场经验 |
|------|------------|---------|
| 业余比赛 | 每级100 | 赢30，平15，输5 |
| 流星联赛 | 每级200 | 赢60，平30，输10 |
| 行星联赛 | 每级350 | 赢100，平50，输15 |
| 恒星联赛 | 每级500 | 赢150，平75，输25 |
| 宇宙小组资格赛 | 每级800 | 赢240，平120，输40 |
| 宇宙杯 | 每级1200 | 赢360，平180，输60 |

### 2.2 降级规则

- 每个段位有保护期：升到新段位后3场比赛内不会降级
- 保护期后，累计输5场降级到下一段位
- 最低段位（业余比赛）不降级

### 2.3 赛季规则

- 每个赛季持续30天
- 赛季结束时根据段位发放奖励：
  - 业余比赛：童话币×500
  - 流星联赛：童话币×1000 + 元灵矿石×20
  - 行星联赛：童话币×2000 + 元灵矿石×50 + 水晶×10
  - 恒星联赛：童话币×5000 + 元灵矿石×100 + 水晶×30
  - 宇宙小组资格赛：童话币×10000 + 元灵矿石×200 + 水晶×60
  - 宇宙杯：童话币×20000 + 元灵矿石×500 + 水晶×120

## 四、AI行为差异

| 段位 | AI特征 |
|------|--------|
| 业余比赛 | 被动防守为主，很少主动进攻，技能用得少且时机差 |
| 流星联赛 | 有基本进攻意识，会传球，技能时机一般 |
| 行星联赛 | 有配合意识，主攻手会找机会进攻，技能时机较好 |
| 恒星联赛 | 战术灵活，会根据局势调整策略，技能时机精准 |
| 宇宙小组资格赛 | 团队配合默契，连招流畅，技能时机完美 |
| 宇宙杯 | 近乎完美的AI，预判玩家动作，技能释放无失误 |
