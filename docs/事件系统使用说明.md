# 事件系统使用说明（人话版）

> 给主人：以后想用事件-响应系统做功能时，看这一页就够了。技术细节在 `docs/副系统-事件触发响应系统方案.md`。

## 一、这个系统是什么

游戏里**看不见但参与判定**的功能（天赋、被动、元素克制……）都走同一条流水线：

```
游戏里发生了一件事（球命中/接住/弹飞/发球/克制命中/冷却结束…）
   → 事件总线"记账+广播"
   → 订阅了这件事的系统自动响应（天赋生效/被动触发/…）
```

**核心好处：加新功能 = 写一份数据，不用改代码。**

## 二、三个开发者工具（主菜单 → 管理员模式）

| 工具 | 干什么 | 改哪个文件 |
|---|---|---|
| **天赋树编辑器** | 拖拽摆位、新增天赋点（名称/描述/触发事件/效果标签）、连前置链 | `data/systems/talent_tree/tree.json` |
| **元素克制编辑器** | 看克制环、点两个元素切换克制关系、改倍率 | `data/spirits/elements.json` |
| 快捷设置 | 原有测试面板 | — |

保存后**重启对局**生效（对局开始时才读数据）。

## 三、加一个功能的 JSON 模板

### 加被动技能（装备元灵的个人自动触发）
在 `data/spirits/skills.json` 的 skills 数组里加：
```json
{"id": "skill_自定义_1", "name": "名字", "type": "passive",
 "trigger": {"event": "Hit.HIT_TAKEN", "condition": {}},
 "cooldown": 8, "energy_cost": 5,
 "tags": ["player_def_up_flat"],
 "tag_params": {"player_def_up_flat": {"duration": 5, "value": 6}}}
```
语义：**每次受到击打 → 扣 5 能量 → 自己防+6 持续 5 秒 → 进 8 秒内冷却**。

### 加天赋点（队伍级）
在 `data/systems/talent_tree/tree.json` 的 nodes 里加：
```json
{"id": "自定义id", "direction": "进攻", "name": "名字", "desc": "玩家看到的说明",
 "requires": ["前置节点id"], "cost": 2, "type": "event",
 "event": "Hit.HIT_COUNTER", "condition": {},
 "tags": ["player_atk_up_flat"],
 "tag_params": {"player_atk_up_flat": {"duration": 5, "value": 8}},
 "cooldown": 10, "energy_cost": 0}
```
语义：**克制命中后全队攻+8 持续 5 秒（10 秒内冷却）**。type 三选：stat（常驻数值）/ event（事件触发全队效果）/ manual（解锁手动技能）。

## 四、可选的触发事件（六大类）

| 类 | 事件 | 触发时机 |
|---|---|---|
| Hit | HIT_TAKEN / HIT_COUNTER / HIT_RESILIENCE_ROLLED / HIT_DEFEATED | 被球打中 / 克制命中 / 韧性判定完 / 被击倒 |
| Attack | ATTACK_LAUNCHED | 发球出手 |
| Defend | CATCH_STANCE / CAUGHT / BOUNCED | 进出接球姿态 / 接住夺球权 / 韧性弹飞 |
| Buff | BUFF_APPLIED / BUFF_EXPIRED / TEAM_EFFECT | 增益施加/到期/全队效果 |
| Status | STATUS_APPLIED / STATUS_EXPIRED | 状态施加/到期 |
| Resource | COOLDOWN_READY / ENERGY_THRESHOLD / STAMINA_THRESHOLD | 冷却结束 / 能量阈值 / 体力阈值 |

## 五、可用效果标签（零件目录）

**见《标签审计报告》**（`docs/标签审计报告.md`）：66 个✅可直接用 / 12 个⚠需要游戏内验证（都是鼠标放置类）/ 2 个❌空壳（ball_avoid、ball_spread，别用）。
天赋树编辑器的效果标签下拉已带 ✅⚠❌ 前缀标注。

## 六、事件账本（改数值前后怎么对比）

每次 `run_sim.sh` 跑完，自动生成 `sim_results/eventlog_seed<N>.json`：
- `category_stats`：各类事件次数（一眼看出"这场弹飞几次/接住几次"）
- `events`：完整事件流水（带时间戳）

**用法**：改某个天赋数值前跑一场存账本 → 改完再跑一场 → 对比两份账本的统计差异 → 数值效果一目了然。

## 七、作用范围铁律

- **被动技能 = 只作用于装备者本人**
- **天赋 event 型 = 全队生效**
- 天赋/被动**永远不能**触发"得分/球权"类事件（比赛公平封闭）
