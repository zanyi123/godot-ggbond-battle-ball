# 原作队伍元灵技能资料（按队伍整理）

> **来源**：百度百科《猪猪侠之竞球小英雄》词条（2026-09-17 抓取，移动端全本）
> **用途**：游戏元灵技能设计的第一手参考素材。角色名/元灵名/技能招式名**逐字保留原作**，机制描述压缩进备注。
> **关联文档**：`技能规划/01_原作元灵技能资料与链路适配.md`（链路适配）、`技能规划/02_元灵技能原语规划.md`（排产）
> **体量**：主角方 2 队 + 对手队伍 49 支，具名技能招式约 **150 个**（组合技计入，等级变体按 1 个计），另有六系元灵之神 12 技。

## 〇、元灵体系设定速览（词条「设定解说」）

### 六大属性与元灵之神（元灵始祖）

| 属性 | 元灵之神（始祖） | 神级技能招式 |
|---|---|---|
| 金刚 | 修罗（金刚之神） | 神之力·裁决之箭、神之手 |
| 草木 | 六叶蝗（草木之神） | 风之守护、藤蔓 |
| 冰雪 | 雪鲸（冰雪之神） | 冰柱、寒霜冻结、暴风雪 |
| 雷火 | 赤鸠（雷火/火焰之神） | 火束、火柱 |
| 大地 | 巨石神兵（大地之神） | 巨石冲击、巨石破 |
| 梦幻 | 仙女龙（梦幻之神） | 龙之舞 |

### 其他关键设定

- **元灵卡**：激活元灵锁召唤元灵用，分四级——普通 / 优秀 / 珍稀 / 传奇（同时代表元灵能量强弱）。
- **元灵锁**：球员佩戴在左手腕、用于召唤自己元灵的装备。
- **元灵晶体**（第 3 季）：影响球员正常状态，可使其元灵技能**消除缺陷**（剧情中实为压榨元灵生命的工具）。
- **联赛等级**：流星联赛（业余）→ 行星联赛（职业）→ 恒星联赛（最高级）→ 宇宙杯（世界顶级赛事）。
- **太阳之子**：每届宇宙杯冠军的称号。获得者：迷糊（第九届，光明队）、巴雷特（上届，永恒队）、猪猪侠（最新一届）。
- **元灵之心**：星图一族与胜域元灵世代守护的信仰，具六系之力，可召唤六系元灵始祖。

### 3.1 体量统计

- **队伍单元**：51 个（小虎队、超人队 + 对手 49 支，含"前/后深渊队"分开计、"幽灵队"为疑似登场）。
- **具名技能招式**：约 **150 个**（组合技计入；"一级/二级/四级新星爆炸"等变体按 1 计；教练技计入；与 01 文档"全收集目标约 150 个"吻合）。
- **属性分布倾向**：对手队中"梦幻"最多（约 18 队）、大地次之，冰雪/雷火/草木居中，金刚最少（仅飞狐队 + 主角方）；做技能原语抽象时注意梦幻系多为"操控/复制/领域/信息"等非直伤机制。
