# AI技能使用系统设计方案

> 创建时间：2026-07-12  
> 状态：待实现

---

## 一、设计目标

让AI球员能够**智能使用元灵技能**，根据场上局势和技能类型做出合理决策：
- BALL类型技能：持球投球前激活，增强球的伤害/速度
- FIELD类型技能：在关键位置放置障碍
- PLAYER类型技能：自身/队友体力低时使用

---

## 二、技能类型与使用策略

### 2.1 BALL类型技能（对球增强）

**使用时机**：
- 持球状态下准备投球时
- 目标敌人距离适中（150-300像素）
- 自身体力充足（>30%）
- 技能冷却就绪

**评分公式**：
```
ball_skill_score = 基础分(50) 
    + 目标距离加成(越近越高)
    + 目标未防备加成(未待接球+20)
    + 体力充足加成(>50%+10)
```

### 2.2 FIELD类型技能（场地障碍）

**使用时机**：
- 无球状态
- 敌人正在推进（带球朝向我方球门）
- 技能冷却就绪

**评分公式**：
```
field_skill_score = 基础分(30)
    + 敌人威胁加成(带球+30, 靠近球门+20)
    + 己方防守压力加成(队友少+20)
```

### 2.3 PLAYER类型技能（球员增强/恢复）

**使用时机**：
- 自身体力低（<30%）或队友体力低
- 技能冷却就绪
- 非击退/非僵直状态

**评分公式**：
```
player_skill_score = 基础分(40)
    + 体力紧急度加成(体力越低越高)
    + 队友需求加成(队友也低+20)
```

## 三、实现步骤

### 步骤1：新增技能决策函数

在 `ai_manager.gd` 中新增：
- `_eval_best_skill(ap)` - 评估当前可用的最佳技能
- `_decide_skill_use(ap)` - 决策是否使用技能
- `_execute_skill(ap, skill_id)` - 执行技能

### 步骤2：集成到AI决策流程

在 `_decide(ap)` 中增加技能决策分支：
- 持球时：评估BALL技能是否值得使用
- 无球时：评估FIELD/PLAYER技能

### 步骤3：技能执行时机

在 `_do_shoot(ap)` 投球前检查是否需要激活BALL技能

---

## 四、参数配置

在 `ai_profile.gd` 中新增：
- `skill_use_threshold` - 技能使用评分阈值（默认40）
- `ball_skill_preference` - BALL技能偏好（主攻手高）
- `field_skill_preference` - FIELD技能偏好（防御手高）
- `player_skill_preference` - PLAYER技能偏好（辅助高）
