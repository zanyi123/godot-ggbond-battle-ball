## 搜索技巧（经验证）

1. **优先搜球类通用词**：`Soccer` / `Goalkeeper` / `Baseball` 球类动作最齐全
2. **动作单词越短越好**：`Throw` > `Overhand Throw`，`Catch` > `Goalkeeper Catch`
3. **注意描述区分**：同名动作（如 `Idle`、`Jump`）有多个变体，看 description 选最合适的
4. **Soccer Game Pack 性价比最高**：54个动画覆盖足球全套动作，决竞球很适配
5. **棒球投球 = 蓄力发球**：`Baseball Pitching` 是最匹配"蓄力发球"的动作，有完整 windup + pitch 流程
6. **先预览再下载**：点缩略图播放预览，确认动作节奏和方向
