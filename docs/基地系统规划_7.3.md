### ① 玩家存档系统（Player Save System）

**优先级**：第1个做
**依赖**：无
**预估规模**：中等

### ④ 训练场地系统（Training System）

**优先级**：第3个做
**依赖**：① 存档系统
**预估规模**：中等

#### 核心功能
- 训练场地等级（解锁属性上限）
- 身体素质训练（永久提升球员基础数值）
- 身体上限训练（提升球员属性天花板）
- 训练消耗 + 训练冷却

#### 球员成长曲线规划系统（核心配套功能）

**什么是成长曲线**：每个球员在不同场地等级下，6项属性（体力/防御/速度/攻击/韧性/球速）的最大上限值是不一样的。场地等级越高，上限越高。成长曲线就是定义"每个球员每级场地上限是多少"的配置表。

**为什么需要单独的规划系统**：
- 7个球员 × 6项属性 × 10级场地 = 420个数值
- 手动一个个改太容易出错，需要可视化工具来调
- 可以用快捷设置系统来做，像球员管理面板那样，滑块调数值

**成长曲线数据结构**（`data/characters/growth_curves.json`）：
```json
{
  "growth_curves": {
    "char_001": {
      "name": "猪猪侠",
      "field_level_1": {
        "stamina_max": 80,
        "defense_max": 60,
        "speed_max": 75,
        "attack_max": 38,
        "resilience_max": 50,
        "ball_speed_max": 420
      },
      "field_level_2": {
        "stamina_max": 88,
        "defense_max": 66,
        "speed_max": 82,
        "attack_max": 42,
        "resilience_max": 55,
        "ball_speed_max": 462
      }
    }
  }
}
```

**配套的开发者工具**：
- 在快捷设置系统中新增「成长曲线规划」面板
- 左侧选球员，中间选场地等级（1~10），右侧滑块调6项属性上限
- 一键应用到所有球员（按比例缩放）
- 一键从角色初始值生成1级曲线
- 已有球员的成长曲线数据自动补全（没配置的用初始值×系数生成默认值）

#### 训练机制

**场地等级与属性上限的关系**：
- 场地等级1 → 读取成长曲线中 field_level_1 的上限
- 场地等级2 → 读取成长曲线中 field_level_2 的上限
- ...以此类推
- 每个球员的上限可以不一样（符合角色定位）

**身体素质训练**：
- 每个属性可单独训练
- 每次训练消耗童话币
- 训练效果永久（写入存档）
- 不能超过当前场地等级对应的成长曲线上限

#### 阈值表（待确认）
| 参数 | 默认值 | 说明 |
|---|---|---|
| 场地最高等级 | 10 | 场地升级上限 |
| 场地升级消耗（1→2级） | 500童话币 | 一级消耗 |
| 场地升级消耗递增 | 1.5倍 | 每级费用是前一级的1.5倍 |
| 每升一级场地，属性上限提升 | 10% | 全属性上限+10% |
| 单次属性训练提升 | 2点 | 每次训练+2属性值 |
| 单次训练消耗 | 100童话币 | 基础训练费用 |
| 训练是否有次数限制 | 无限制 | 只要有钱就能练 |
| 训练冷却时间 | 0 | 无冷却 |

#### 改动文件
- 新建：`scripts/systems/training/training_manager.gd`

#### 独立验证
- 训练属性 → 数值上升 + 存档后不丢
- 训练到上限 → 不能继续训练该属性
- 升级场地 → 上限提高，训练可继续
- 训练消耗 → 货币正确扣减

### ⑧ 快捷系统扩展（开发者工具）

**优先级**：第8个做
**依赖**：③ 装备系统 + ⑤ 营养系统 + ④ 训练场地系统
**预估规模**：中

#### 核心功能
在现有快捷设置系统中新增4个入口：

**1. 装备管理面板**（参考球员管理模式）
- 快速新建装备（手套/球衣/球鞋）
- 滑块调整主属性、副属性数值
- **稀有度下拉选择框**（普通/良好/稀有/史诗/传说，对应5档颜色）
- 一键生成测试装备套
- 导入/导出装备JSON

**2. 食物管理面板**（参考元灵管理模式）
- 快速新建食物
- 滑块调整buff数值、持续时间
- **稀有度下拉选择框**（5档，同上）
- 一键生成测试食物包
- 导入/导出食物JSON

**3. 成长曲线规划面板**（新增）
- 左侧球员列表，选择要编辑的球员
- 中间场地等级滑块（1~10级）
- 右侧6项属性上限滑块（体力/防御/速度/攻击/韧性/球速）
- 一键从初始值生成1级曲线
- 一键按比例缩放所有等级（比如整体+10%）
- 一键复制到所有球员（按比例适配）
- 已有球员自动补全缺失的等级数据
- 实时预览：表格展示该球员10级的全属性上限变化

**4. 物资发放面板**
- 给当前存档发货币（童话币/矿石/水晶）
- 给当前存档发装备/食物
- 一键解锁全部角色
- 一键训练满级
- 一键装备全解锁

#### 参考实现
