# AccuRIG 2.1 完整操作手册（决竞球项目专用）

> **版本**：v1.0（2026-07-14）
> **适用**：AccuRIG 2.1.0（Reallusion 免费自动绑骨工具）
> **用途**：混元3D生成的Q版球员模型 → AccuRIG自动绑骨 → 导出带骨骼FBX → 去Mixamo下动画
> **前提**：已通过 `auto_3d_model.py` 脚本生成 `player2.fbx`（28MB左右，已减面+修复）

---

## 一、AccuRIG 界面总览

启动AccuRIG后，界面分为 **左侧步骤栏** 和 **中间3D视图** 两大部分：

```
┌──────────────────────────────────────────────────────────────────────┐
│  顶部： AccuRIG | Add Motions | 各种工具栏图标                        │
├──────────┬───────────────────────────────────────────────────────────┤
│          │                                                           │
│  步骤1   │                                                           │
│ Load     │                                                           │
│ Character│         中间 3D 视图（模型显示区）                        │
│          │                                                           │
│  步骤2   │                                                           │
│ Check    │                                                           │
│ Model    │                                                           │
│          │                                                           │
│  步骤3   │                                                           │
│ Rig      │                                                           │
│ Body     │                                                           │
│          │                                                           │
│  步骤4   │                                                           │
│ Rig      │                                                           │
│ Hand     │                                                           │
│          │                                                           │
│  步骤5   │                                                           │
│ Calibrate│                                                           │
│          │                                                           │
└──────────┴───────────────────────────────────────────────────────────┘
```

**左侧5个步骤（从上到下）：**

| 步骤 | 名称 | 做什么 | 耗时 |
|------|------|--------|------|
| 1 | **Load Character** | 导入FBX模型 | 1-2分钟 |
| 2 | **Check Model** | 检查模型姿态/朝向 | 1分钟 |
| 3 | **Rig Body** | 身体骨骼自动绑定 + 调整关节点 | 3-5分钟 |
| 4 | **Rig Hand** | 手指骨骼自动绑定 | 2分钟 |
| 5 | **Calibrate** | 校准T-pose姿态 | 2分钟 |

> ⚠️ **关键认知**：关节点调整主要在 **步骤3 Rig Body** 里做，不是在 Calibrate。Calibrate 是最后微调姿态用的。

## 二、完整操作流程（一步一步来）

### 步骤1：Load Character（导入模型）

**目的**：把Blender转好的FBX导入AccuRIG。

**操作：**
1. 启动AccuRIG，默认在步骤1（Load Character，绿色高亮）
2. 中间视图有个虚线框，写着 "Please drag-and-drop character file here (FBX, OBJ)"
3. 点中间的 **"Choose File"** 绿色按钮
4. 找到 `E:\项目储存\决竞球battle-ball\建模素材库\3D模型素材\player2.fbx`
5. 点 **Open**
6. 等待导入（1-2分钟，看模型大小）

**导入完成后：**
- 模型出现在中间3D视图中
- 左上角显示模型信息：
  - `Total tris: 74978`（三角面数，越小越快）
  - `Character height: 110.78 cm`（角色身高）

**3D视图操作：**
| 操作 | 方法 |
|------|------|
| 旋转视角 | 鼠标中键拖动 |
| 缩放 | 鼠标滚轮 |
| 平移 | Shift + 中键拖动 |

---

### 步骤2：Check Model（检查模型）

**目的**：确认模型姿态正确、朝向正确。

**操作：**
1. 导入完成后，左侧会自动跳到步骤2（Check Model）
2. 检查模型：

**检查项：**
- ✅ 模型是 **T-pose**（双臂水平张开）
- ✅ 正面朝向屏幕（脸对着你）
- ✅ 双脚站稳在地面上（不是悬空）
- ✅ 模型完整，无残缺

**如果姿态不对：**
- 不是T-pose → 回混元重新生模型，参考图必须T-pose
- 朝向反了 → 用左侧工具栏的旋转工具调整（一般不用）

**确认没问题后：**
- 点左侧的 **步骤3 Rig Body**（或等自动下一步）

---

### 步骤3：Rig Body（身体绑骨）⭐ 核心步骤

**目的**：自动检测身体关节点，生成身体骨骼。**关节点调整主要在这里做！**

**操作：**

#### 3.1 自动检测
1. 进入Rig Body步骤后，AccuRIG会**自动在模型上放置关节标记点**
2. 模型上出现一堆**黄色/彩色的小圆点**（关节标记）
3. 这些点就是骨骼的关节位置

#### 3.2 认识关节点

身体主要关节点（从上到下）：

| 部位 | 数量 | 位置 |
|------|------|------|
| 头部 | 2-3个 | 头顶、下巴、脖子根 |
| 肩膀 | 2个（左右各一） | 脖子根和肩膀连接处 |
| 手肘 | 2个（左右各一） | 手臂中段 |
| 手腕 | 2个（左右各一） | 手掌根部 |
| 脊椎 | 3-5个 | 背部中线 |
| 盆骨 | 1个 | 腰部中间 |
| 膝盖 | 2个（左右各一） | 大腿小腿连接处 |
| 脚踝 | 2个（左右各一） | 小腿和脚连接处 |

#### 3.3 调整关节点（Q版模型必须做！）

> ⚠️ **Q版大头小身模型，自动检测的点肯定不准，必须手动调！**

**调整方法：**
1. 鼠标移到一个黄色点上
2. **左键按住**这个点（不要松）
3. **拖动**到正确的关节位置
4. 松开左键，点会吸附到新位置

**Q版模型重点调整的点：**

| 部位 | 常见问题 | 怎么调 |
|------|----------|--------|
| **头顶** | 自动检测的点可能太低 | 往上拖到头顶最高点 |
| **下巴** | 自动检测的点可能太高/太低 | 拖到下巴尖正下方 |
| **脖子根** | 头太大，脖子位置不对 | 拖到头和身体连接处 |
| **肩膀** | Q版肩膀窄，点可能偏内 | 往外拖到肩膀最宽处 |
| **盆骨** | 身体短，位置不对 | 拖到两腿中间上方 |

**调整技巧：**
- 滚轮放大看清楚
- 中键旋转从侧面确认位置
- 左右对称的点，只调一边？不，AccuRIG是左右各一个点，都要调
- 调错了没关系，再拖一次就行

#### 3.4 生成身体骨骼

关节点都调准后：
1. 找右下角的 **"Create Rig"** 或 **"Next"** 按钮
2. 点它
3. 等待几秒，身体骨骼生成完成
4. 模型上出现半透明的骨架

#### 3.5 预览测试

生成完会自动播放一个预览动作（挥手之类的）：

**检查：**
- ✅ 肩膀动作自然
- ✅ 手肘朝后弯（不是朝前）
- ✅ 膝盖朝前弯（不是朝后）
- ✅ 没有严重穿模

**如果扭曲严重：**
- 点 **"Undo"** 或回到上一步
- 重新调整关节点
- 再次 Create Rig

---

### 步骤4：Rig Hand（手指绑骨）

**目的**：给手指加骨骼。Q版模型手指可能粘连，这步可以简单处理。

**操作：**
1. 身体骨骼生成完，自动跳到步骤4（Rig Hand）
2. AccuRIG自动检测手指关节

**Q版模型注意：**
- 如果手指粘连严重（混元生成的Q版模型常见），手指骨骼可能不准
- **游戏用要求不高的话，手指骨骼可以简化**，不影响身体动画
- 如果手指完全不对，也可以跳过这步（身体骨骼够用了）

**确认手指骨骼没问题后：**
1. 点 **"Next"** 或 **"Create Hand Rig"**
2. 等待生成

---

### 步骤5：Calibrate（校准姿态）

**目的**：微调T-pose姿态，确保骨骼完全对齐。

> 注意：Calibrate **不是**用来调关节点位置的，关节点位置在步骤3 Rig Body里调。
> Calibrate是调**姿态角度**的（比如手臂有没有完全水平、脚有没有并拢）。

**操作：**
1. 进入Calibrate步骤
2. 模型保持T-pose
3. 可以微调：
   - 手臂角度（确保完全水平）
   - 双脚间距
   - 手掌朝向
4. 点 **"Finish"** 或 **"Done"** 完成

**Q版模型常见问题：头部变形**
- 如果Calibrate后头部看起来变形/拉伸了 → 说明步骤3的头部关节点没放对
- **回去步骤3 Rig Body，重新调头部的点**，再重新生成骨骼

## 三、导出带骨骼的FBX

绑骨完成后，导出给Mixamo或Godot用。

### 方法A：导出基础骨骼模型（推荐，给Mixamo用）

1. 顶部菜单 **File → Export** 或 **Export As**
2. 弹出导出设置窗口

**导出设置：**

| 选项 | 选什么 | 原因 |
|------|--------|------|
| 格式 | **FBX** | 通用格式 |
| Include Animation | **不勾** ⚠️ | 只要模型+骨骼，不要动画 |
| Include Skin / Mesh | **勾** | 带模型网格 |
| Include Textures | **勾** | 带贴图 |
| Scale | 1.0 | 不改 |
| Forward | -Z Forward | 游戏引擎标准 |
| Up | Y Up | 游戏引擎标准 |

3. 文件名：`player2_rigged.fbx`
4. 保存到：`建模素材库/3D模型素材/player2_rigged.fbx`
5. 点 **Export**

### 方法B：带动画导出（如果用AccuRIG的动画库）

如果不用Mixamo，直接在AccuRIG里下动画：

1. 顶部切到 **"Add Motions"** 标签
2. 在动画库里搜：Idle、Jog、Throw、Stumble
3. 选中动画 → 点 **Apply** 应用到模型
4. 每个动画分别导出：
   - File → Export
   - **勾上 Include Animation**
   - 命名：`player2_idle.fbx`、`player2_run.fbx` 等

## 四、后续流程（回到脚本）

AccuRIG绑骨完成后，有两条路：

### 路线A：AccuRIG绑骨 + Mixamo下动画（推荐）

1. AccuRIG导出 `player2_rigged.fbx`（只有骨骼，没有动画）
2. 打开 https://www.mixamo.com
3. **上传 `player2_rigged.fbx`**（不是原始的player2.fbx！）
4. Mixamo识别到已绑骨的模型，直接进动画库
5. 搜并下载4个动画（Idle/Jog/Throw/Stumble）
6. 下载设置：Format=FBX for Unity, Include Skin=勾, In Place=勾, FPS=30
7. 下载的文件放到 `建模素材库/3D模型素材/player2动作/`
8. 跑脚本继续：
   ```cmd
   python tools/auto_3d_model.py player2
   ```

### 路线B：全用AccuRIG（动画少）

1. AccuRIG的Add Motions里找动画
2. 每个动画分别导出FBX
3. 放到 `player2动作/` 目录
4. 跑脚本继续

## 五、常见问题排查

| 问题 | 原因 | 解决 |
|------|------|------|
| 导入FBX卡住很久 | 模型太大（面数多/贴图大） | 用脚本重新生成，已自动减面 |
| Rig Body后头部变形 | 头部关节点没放对 | 回步骤3，调头顶/下巴/脖子根的点 |
| 手臂动作扭曲 | 肩膀/手肘/手腕点不对 | 回步骤3，沿手臂中心线调整 |
| 腿动作扭曲 | 盆骨/膝盖/脚踝点不对 | 回步骤3，调腿部点 |
| 手指完全不对 | Q版手指粘连 | 可以跳过Rig Hand，不影响身体动画 |
| Calibrate后模型变形 | 关节点基础位置错了 | 回步骤3 Rig Body重新调点 |
| 导出文件太大 | 面数多+贴图大 | 脚本已做减面和贴图压缩 |
| 找不到导出按钮 | 在顶部File菜单 | File → Export |

## 六、决竞球项目推荐工作流

```
即梦生T-pose参考图
       ↓
混元3D图生3D（下载GLB）
       ↓
auto_3d_model.py 脚本
  ├─ 步骤1：参考图管理 ✅
  ├─ 步骤2：自动识别GLB ✅
  └─ 步骤3：Blender转FBX + 减面 + 修复 ✅  ← 输出 player2.fbx
       ↓
AccuRIG 手动绑骨（本教程）
  ├─ Load Character ← 导入 player2.fbx
  ├─ Check Model（检查T-pose）
  ├─ Rig Body ⭐ 调关节点 → 生成骨骼
  ├─ Rig Hand（可选）
  └─ Calibrate → 完成
       ↓
导出 player2_rigged.fbx
       ↓
Mixamo 下载4个动画
       ↓
auto_3d_model.py 脚本继续
  ├─ 步骤4：检测动画文件
  └─ 步骤5：复制到Godot assets/characters/avatars/
       ↓
Godot 导入使用
```
