### 下载教程

#### 步骤一：注册 itch.io 账号

1. 打开 https://itch.io/register
2. 填写用户名、邮箱、密码
3. 验证邮箱

#### 步骤二：下载免费特效包

1. 打开特效包链接（如 https://binbun3d.itch.io/elemental-magic-fx）
2. 点击 **"Download Now"** 按钮
3. 弹出价格输入框：
   - 如果显示 "Name Your Own Price"：输入 **0**，然后点 **"No thanks, just take me to the downloads"**
   - 如果显示固定价格（如 $4.49）：该包为付费包，换一个免费的
4. 选择下载格式（通常只有 zip）
5. 下载得到 `.zip` 压缩包

#### 步骤三：导入 Godot 项目

1. 解压 `.zip` 文件
2. 将解压出的 `assets/` 文件夹**整体拖到**你的 Godot 项目根目录
   - 如果已有 `assets/` 文件夹，选择**覆盖合并**
3. 特效文件路径示例：`assets/BinbunVFX_Vol2/ElementalMagicFX/effects/`
4. 在 Godot 的 FileSystem 面板中找到 `.tscn` 场景文件
5. **直接拖进你的 3D 场景**即可使用
6. 选中特效节点 → 勾选 `emitting` 属性 → 即可看到效果

#### 步骤四：自定义特效参数

- **颜色**：选中 GPUParticles3D 节点 → `Process Material` → `ParticleProcessMaterial` → 修改 `Color` 或 `Color Ramp`
- **大小**：修改 `Scale Min/Max`
- **时长**：修改 `Lifetime`
- **粒子数量**：修改 `Amount`

### 下载教程

#### 步骤一：注册 Unity 账号

1. 打开 https://id.unity.com
2. 注册账号（邮箱验证）

#### 步骤二：添加到 My Assets

1. 打开特效包页面（如 https://assetstore.unity.com/packages/vfx/particles/spells/magic-effects-free-247933）
2. 点击 **"Add to My Assets"** 按钮
3. 等待添加完成

#### 步骤三：下载

**方式一：通过 Unity Editor 下载（需要有 Unity）**

1. 打开 Unity Hub → 安装任意版本 Unity
2. 创建空项目 → 打开
3. 菜单 `Window > Package Manager`
4. 切换到 **"My Assets"** 标签
5. 找到添加的特效包 → 点 **"Download"** → **"Import"**
6. 导入后，资源会出现在项目的 `Assets/` 目录下

**方式二：不用装 Unity，直接解包（推荐）**

1. 从 Unity Asset Store 网页下载 `.unitypackage` 文件
2. `.unitypackage` 实际上是 `tar.gz` 压缩包
3. 用 7-Zip 或 tar 命令解压：
   ```bash
   # 方法1：用 7-Zip
   # 右键 .unitypackage → 7-Zip → 解压到当前文件夹
   # 再解压里面的 .tar 文件

   # 方法2：用命令行
   tar -xzf package.unitypackage
   ```
4. 解压后会得到一堆文件，**只需要 PNG 贴图和序列帧**
5. Unity 的 `.prefab`、`.asset`、`.cs` 文件不需要

### 提取贴图后在 Godot 中使用

#### 场景一：PNG 序列帧 → AnimatedSprite3D

1. 将提取的 PNG 序列帧导入 Godot 项目的 `assets/vfx_textures/` 目录
2. Godot 会自动导入 PNG
3. 选中所有序列帧 PNG → 右键 → **"Create New SpriteFrames"**
4. 将生成的 SpriteFrames 资源拖到 `AnimatedSprite3D` 节点的 `Sprite Frames` 属性
5. 设置动画播放

#### 场景二：PNG 贴图 → GPUParticles3D 粒子材质

1. 将 PNG 贴图导入 Godot
2. 创建 `GPUParticles3D` 节点
3. 创建 `ParticleProcessMaterial` 资源
4. 在 `ParticleProcessMaterial` 中找到 `Texture` 属性
5. 将 PNG 贴图拖入 `Texture` 属性
6. 调整粒子参数（数量、寿命、速度、颜色等）

## 7. 通用：导入 Godot 后如何挂到 3D 角色模型上

### 决竞球的 2.5D 架构说明

决竞球使用 2.5D 架构：`CharacterBody2D → SubViewport + Camera3D → ViewportTexture → Sprite2D`

3D 特效需要放在 **SubViewport 内的 3D 场景**中，跟 3D 球员模型在同一个 3D 空间里。

### 步骤一：确认 3D 场景结构

```
CharacterBody2D（2D 物理层）
  └── SubViewport（3D 渲染层）
       └── Camera3D
       └── ModelSlot（3D 球员模型）
       └── GPUParticles3D ← 技能特效放这里
```

### 步骤二：添加特效节点

```gdscript
# 在球员脚本中添加技能特效
func play_skill_effect(effect_scene_path: String):
    var effect_scene = load(effect_scene_path)
    var effect = effect_scene.instantiate()
    
    # 获取 SubViewport 内的 3D 场景根节点
    var viewport_3d = $SubViewport  # 根据实际节点路径调整
    
    # 添加到 3D 场景中
    viewport_3d.add_child(effect)
    
    # 设置位置（在球员脚下或身上）
    effect.global_position = model_slot.global_position
    
    # 自动清理（特效播放完后删除）
    if effect.has_signal("finished"):
        effect.finished.connect(effect.queue_free)
    else:
        # 设置定时器自动删除
        var timer = Timer.new()
        timer.wait_time = 3.0  # 3秒后删除
        timer.one_shot = true
        timer.timeout.connect(effect.queue_free)
        add_child(timer)
        timer.start()
```

### 步骤三：元素颜色映射

```gdscript
# 元灵技能特效颜色配置
const ELEMENT_COLORS = {
    "metal":    Color(1.0, 0.84, 0.0),    # 金刚 - 金色
    "dream":    Color(0.6, 0.2, 0.8),     # 梦幻 - 紫色
    "grass":    Color(0.3, 0.9, 0.3),     # 草木 - 绿色
    "thunder":  Color(1.0, 0.8, 0.2),     # 雷火 - 橙黄
    "ice":      Color(0.5, 0.8, 1.0),     # 冰雪 - 浅蓝
    "earth":    Color(0.6, 0.4, 0.2),     # 大地 - 土色
}

func apply_element_color(particles: GPUParticles3D, element: String):
    var color = ELEMENT_COLORS.get(element, Color.WHITE)
    var mat = particles.process_material as ParticleProcessMaterial
    if mat:
        mat.color = color
```

### 注意事项

1. **GODOT-VFX-LIBRARY 是 2D 的**（CPUParticles2D），不能给 3D 模型用，已弃用
2. Binbun3D 和 VFX Sketchbook 的特效是 **3D 的**（GPUParticles3D），适合 3D 模型
3. 特效需要跟 3D 球员模型放在**同一个 SubViewport** 内才能正确渲染
4. 注意特效的 `Lifetime` 不要太长，技能特效通常 1-3 秒
5. 用 `emitting = false` → `emitting = true` 的方式触发一次性特效
