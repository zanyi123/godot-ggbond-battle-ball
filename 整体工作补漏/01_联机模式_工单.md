## 一、目标一句话

主菜单点「联机对战」后：房主建房（选模式）或随机匹配，同局域网玩家在房间列表直接看到点击即入（异网用房间码直连，后期支持无房间码随机匹配）→ 匹配成功等 20 秒（每队自动定队长）→ 进**选角**（双方盲选，球员/元灵不可重复，人机位自动补选）→ **加载界面**以王者荣耀式 VS 角色卡亮出双方阵容 → 进入与单机逻辑一致的比赛；备战与中场面板**全员准备+队长确认**才继续（超时再等 15 秒未准备者判负）；挂机/掉线玩家**AI 托管+全程小字播报**不干扰比赛；每个玩家画面**己方永远在左**；房间与对局全程可**打字聊天+开麦语音**联络（盲选与对局阶段仅同队频道，敌我战术不互通）。

## 二、模式定义（本期三档）

| 档位 | 内部代号 | 人数构成 | 队长 |
|---|---|---|---|
| 1v1 | `MP_1V1` | 2 玩家，每队 1 名上场球员 | 玩家即队长（准备=确认，按钮合一，见裁定 D4） |
| 3v3 人机 | `MP_3V3_COOP` | 队伍A = 3 玩家（各控 1 名固定球员）；队伍B = 3 AI | A 队队长=建房者（槽位0） |
| 3v3 全人 | `MP_3V3_6P` | 6 玩家，各控 1 名固定球员 | 每队队长=该队最早入队者（槽位0） |

- 联机模式**每人固定控制自己的球员**，禁用单机「1/2/3/Tab 切换」；单机模式行为完全不变。
- 3v3 人机档敌方 3 AI **自动选角**：策略子任务交**元灵技能AI板块**（§五 S3），接口未接前主机按剩余池随机兜底。
- 元灵选角池=6 个正式元灵，`spirits.json` 3 个验收条目不进池。
- 1v1 用正常全场 1300×780（主人裁定 2026-10-26）；1v1 平衡调优不在本单（归游戏机制优化域）。

### S0 总则：四层架构 + 接口契约 + 契约先行（低温，定死）

**S0.1 同步架构**：**主机权威 + 状态快照 + 客户端插值，禁用确定性锁步**。物理（Area2D）跨机不可逐位一致；host=唯一权威实例（AI、球物理、比分、计时、阶段、托管判定都在 host 跑），guest=只渲染+上报输入（与项目「2D 逻辑权威」同构，改动面最小）。输入指令上行 ≥20Hz，快照下行 ≥20Hz，guest 100ms 缓冲插值。

**S0.2 四层架构**：

| 层 | 职责 | 载体 |
|---|---|---|
| 传输层 | ENet P2P / UDP 广播发现 / S12 Relay | `net_transport.gd` |
| 会话层 | 房间状态机、槽位、队长、心跳、就绪、判负、托管 | `autoload/net_manager.gd` |
| 同步层 | 指令上行、快照下行、事件广播、时钟 | `net_sync.gd` |
| 表现层 | 镜像相机、HUD 播报、等待门 UI、VS 卡 | 各 UI/相机脚本 |

### S3 选角阶段（新建独立场景，单机不经过）

- 流程：匹配等待 20s（D3）→ 选角**盲选**（不可见对方已选）→ 各自锁定 → host 汇总仲裁 → 全员锁定进加载；锁定倒计时 60s，到点未锁者随机/沿用上局默认。
- **不可重复（D16，v3 改）**：**仅队内唯一，敌我可重复**（两队选同款球员/元灵合法，主人批 1026-9）；host 仲裁只查本队内冲突，队内撞车者收「队友已选」提示重选；池子维持 7 球员/6 元灵不扩。
- AI 位自动补选：host 调元灵技能AI板块策略接口（子任务移交，接口先定：`pick_character/pick_spirit(available, team_picks) -> id`，可选池=**本队内**剩余）；未就绪随机兜底。
- 选角界面线框：左右两栏己方视角（己方明/对方隐）、卡片网格、锁定按钮+倒计时；视觉规范对齐操控与基础Ui规划域。

### S4 加载界面（新建，王者荣耀式 VS 卡）

- 布局：左己方 3 张角色卡（球员立绘/名字+元灵小框）· 中「VS」标 · 右敌方 3 张——**盲选到此为止，此页首次亮阵**（己方在左同样适用，见 S8）。
- 加载语义：预载 battle_arena 资源 + host 组包阵容；`本地加载完成 + 收到 host 开赛包` 双条件才切场景；**加载期任一人掉线/超时（60s 常量）未就绪=全场取消回大厅（D15）**。
- 卡面资产依赖美术域（v1 占位模板）；终验走「待主人终验」。

### S5 战斗权威同步（改 battle_manager / game_manager / player / ball / ai_manager / input_manager）

- `game_manager`：比分/计时/阶段只认 host；guest 禁用本地倒计时与 `_advance_phase`，阶段变更走网络事件；`pause_match/freeze_all` host 广播生效。
- `battle_manager._setup_teams()` → 新增 `configure_match(config)`（模式、双方球员 id 序、元灵、出生点表、槽位→peer 映射）；单机默认配置=现硬编码（读数不变）。
- 输入指令化：本地读入 → `InputCommand` 上行；**guest 方向向量先按镜像换算回世界坐标再上行**（S8）；host 收指令驱动对应 player。
- `player.is_player_controlled` → `controlled_by_peer`（NONE/HOST/PEER#）；`ai_manager._is_valid()` 跳过**所有**人类位；**AI 只在 host 跑**，guest 不注册。
- `ball.gd` 物理与接投球判定仅 host 权威；得分/击中事件 host 广播。
- 联机下禁用切换键（1/2/3/Tab）；battle_hud 技能栏只显示自己球员的技能；快捷消息走网络转发（v1 支持）。

### S6 模式配置化（1v1 支持）

- 模式常量表：上场人数/出生点表/流放区参数按档切换（1v1 出生点按现 3v3 左右位推导单点位，方案截图待主人终验）；**1v1 场地=正常全场 1300×780**（主人裁定）。
- 体力/技能数值 1v1 平衡不在本单（归游戏机制优化域），本单只保证可玩不炸。

### S7 等待门：匹配 20s + 队长确认 + 超时判负（主人 2026-10-26 批复）

- **匹配等待门**：房间满员 → 20s 倒计时进选角（D3）；期间显示各队队长任命（D10）；**到点有人未就绪或期间任一人掉线=全场取消回大厅（D15，v3）**；选角阶段掉线/超时同走 D15 取消制。
- **备战面板（联机版）**：保留装备/查看阵容，**换人锁定**（选角已定）；个人「准备」+ 队长「开始比赛」双条件（D2）；面板倒计时 60s（D5）→ +15s 宽限（D6）→ 仍未就绪者判负（D7）→ 门重算自动继续。
- **中场面板（联机版）**：同规则（全员准备+队长「继续比赛」；60s+15s+判负 D7）；中场换装保留、换人锁定。
- **结算面板**：全员确认回大厅；30s 到点自动回（比赛已结束无判负必要，裁定）；**联机奖励（v3 按 1026-10）：发奖功能完整实现但挂开关默认关——测试期不实验、不上线，上线节奏与数值口径（人机档减半等）由主人后批**。
- 等待期间冻结复用 `freeze_all/pause_match`；各端门状态由 host 广播 `GateState` 驱动，禁止各端自行推进。

### S8 相机对称渲染（己方永远在左）

- 2D 逻辑层**不动**（A 左 B 右语义不变）；guest（B 队位）`camera_3d_controller` 新增镜像机位（绕场心 yaw 180°），等效己方渲染到屏幕左侧。
- 输入方向换算：guest 屏幕方向→世界方向与镜像互逆，保证「按左=往屏幕左走」。
- HUD 侧序镜像：计分板己方在左、技能/体力条「己下敌上」镜像（`battle_hud.gd` 视角参数）；VS 卡/选角界面同律己方在左。
- host（A 队）视角=现单机；单机模式零变化。

### S9 挂机/掉线/判负统一策略（主人 2026-10-26 批复：小字播报，不干扰比赛）

- **挂机（D8）**：host 检测某 peer **10s 无指令** → 摘受控标记转 AI 托管（D12）→ `NoticeEvent` 小字播报+角标常驻；一有输入立即归还+播报「已回归」。**不暂停、不弹窗**。
- **掉线（D9）**：心跳超时 → 同托管+播报；对局内重进房间夺回原槽位（判负出局者除外）。
- **房主/host 掉线（D14，v3 新增）**：非 host 端检测 host 心跳超时（6s）→ 全场冻结+播报「房主转移」→ 接任端（剩余端按槽位序最前者）从**最新快照**重建权威续跑，比赛继续不判负；原 host 重连=以普通玩家身份夺回原槽位（本局不再自动收回 host）；等待阶段 host 掉线走 D15 取消制；1v1 对局内 host 掉线=对手接任+掉线者转 AI 托管，比赛继续。
- **判负（D7）**：仅发生在门禁超时（S7）；1v1 整场结算，3v3 个人出局转托管、比赛继续；队长判负→D10 顺延转让。
- **托管 AI 参数**：用哪套 ai_profile（建议新建「托管档」介于主攻/辅助之间）→ 子任务移交元灵技能AI板块，未就绪前用默认 profile。
- 弱网提示：RTT>300ms 或丢包 HUD 图标（阈值实现窗口定）；全队/全场只剩 AI 时比赛正常打完（不中断结算）。

### S10 异网直连（已批 A，M4）

- UPnP 自动端口映射（Godot 内置 UPnP 类）+ 房间码直连（D13：`公网IP:端口` 短码封装+校验）；打洞失败场景由 S12 Relay 兜底。
- 异网与 LAN 完全复用同一套会话/同步/门禁逻辑，**不做两套**。

### S12 随机匹配 + 中心服务（主人批「服务器用就用了」；**本节即设计**，实施 M5）

**S12.1 服务形态**：单台轻量云服务器，三组件一套：
| 组件 | 协议 | 职责 |
|---|---|---|
| Matchmaker 匹配器 | WebSocket(JSON) | 按模式分队列，先到先配（v1 无段位；远期可挂 ELO）；凑齐即下发房间令牌+成员表+队长（每队最早入队者） |
| Directory 房间码目录 | WebSocket(JSON) | 房间码↔公网端点映射（异网好友邀请不必裸传 IP） |
| Relay 中继 | UDP 转发 | 直连（UPnP/打洞）失败时的流量转发兜底 |

**S12.2 流程**：客户端→Matchmaker 注册(模式, 匿名设备ID)→凑齐→下发成员列表→成员间 P2P 直连（S10）→失败自动切 Relay→对局（host 权威不变，host=队长方槽0）→结果回传（可选统计）。
**S12.3 边界**：服务器**只做撮合与转发，不跑游戏逻辑**（权威仍在玩家 host，省服务器算力）；断线/判负/门禁全部复用 S7/S9，不另做一套。
**S12.4 选型建议**：Go 单二进制（WebSocket+UDP 一个进程）部署单台轻量云主机；备选 Godot headless 服务端复用 GDScript 协议代码——实现窗口开工 M5 前出 2-3 案报主人（含月成本估算）。
**S12.5 部署与成本形态**（云厂商/规格/地域）→ M5 开工前单列小决策进《待主人决策.md》。

### S13 通讯与联络：打字聊天 + 开麦语音（主人令 2026-10-27 补，v4）

**S13.1 频道矩阵（=裁定 D18，全阶段定死）**：

| 阶段 | 打字聊天 | 语音开麦 | 快捷消息 |
|---|---|---|---|
| 大厅/房间 + 匹配等待 20s | 全员 | 全员 | — |
| 选角（盲选） | 仅同队 | 仅同队 | — |
| 对局（含备战/中场面板） | 仅同队（1v1 无对象=禁用） | 仅同队（1v1 同） | 全员（沿用现有快捷消息栏） |
| 结算 | 全员 | 全员 | — |

**S13.2 打字聊天（并入 M2）**：
- 协议：`ChatMessage {channel: room|team, from_peer, from_name, text(≤100字), ts}`，走 reliable 通道；host 收→按频道+当前阶段（D18）判收件人→转发（D22）。
- UI：房间/大厅右侧聊天栏（历史可滚动+输入框）；对局中小字半透明聊天气泡（最近 2 条，6s 淡出）+ 回车唤起输入条（D23：输入期间屏蔽游戏按键）；选角界面同队侧栏。
- 防刷屏：每人 10s 内最多 5 条，超限静默丢弃+本地提示；空消息不发；聊天记录不持久化（v1）。
- 与播报分工：D11 播报=系统事件（挂机/判负/队长/房主转移），聊天=玩家发言；同区显示、不同配色与前缀。

**S13.3 语音开麦（并入 M4，M3 期间可先做采集管线 spike 不阻塞主线）**：
- 采集：`AudioEffectCapture`（Godot 原生，默认输入设备+音量滑条；设备选择后置）；播放：`AudioStreamGenerator` 接收端本地混音多路后推送。
- 编码（D21）：PCM 16bit 8kHz 单声道（≈128kbps/人）或 IMA-ADPCM（≈32kbps/人）二选一。**带宽账（6 人房最坏 5 路同说）**：PCM≈640kbps / ADPCM≈160kbps——LAN 均稳，公网（M4/M5）建议 ADPCM；实现窗口据此定死其一并回填本节。
- 传输：ENet **unreliable 独立通道**（与游戏快照通道分开，互不挤占），40ms/包；丢包=轻微杂音不重传；掉线即停该路（心跳同判）。
- 开麦模式（D20）：常开切换 + PTT 按住说话，默认 PTT；键位归操控域键位表（跨域移交+1）。
- 指示：说话者名字旁实时喇叭动效（房间槽位/对局 HUD 队友栏）；开闭麦状态全员可见（D19 默认闭麦且闭麦不采集）。
- 隐私与降级：麦克风权限失败/无设备→提示并保持文字可用；语音不落盘不存档不转发给频道外任何人。
- 回声：v1 **不做 AEC**，明示「建议戴耳机」（写进 UI 提示）；外放回声列为已知限制，AEC 二期评估（R11）。
- 托管/掉线交互：托管不影响说话（人还在就能说，D12 只接管操作）；判负出局者移出语音频道。
