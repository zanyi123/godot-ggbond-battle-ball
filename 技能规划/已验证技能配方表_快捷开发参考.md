## 字段还原规则（先读）

| 字段类别 | 字段 | 还原规则 |
|---|---|---|
| **效果结构字段**（照抄=效果保真） | element / type / operator / energy_cost / cooldown / tags / tag_params | **逐字照抄**——尤其 tag_params 的参数键名（value/multiplier/duration…），错一个字符=参数丢失（金刚_1 事故） |
| **身份字段**（转正式时自定义） | id / name / description / base_description / detail / icon_path / icon_color / unlock_level / unlock_cost | 测试技现值带"(测)""端到端测试技"测试标记，**转正式必须替换**（id 遵循 skill_元灵_N 命名习惯） |
| **可调项** | tag_params 内的数值 | 数值可调（范围见各卡），键名和结构不可动 |

| 原作出处 | 内容 |
|---|---|
| 持有球员 | **菲菲（队长，内场主攻手）** |
| 元灵 | **玲珑（原型火凤凰）**｜雷火系 |
| 原作介绍 | 将能量注入球中，操控元灵体与球，命中对方造成**高额范围伤害** |

**字段还原表**

| 字段 | 值（照抄） |
|---|---|
| element 元素 | 雷火 |
| type 类型 | active |
| **operator 操控方式** | **OP_AIM**（激活后瞄准目标） |
| energy_cost 能量消耗 | 20 |
| cooldown 冷却 | 10.0 |
| **tags 技能标签（按序声明）** | ① ball_dmg_up_pct（增伤%）② ball_speed_up_pct（加速%） |
| **tag_params 标签参数** | ball_dmg_up_pct → {"value": 40.0}<br>ball_speed_up_pct → {"multiplier": 1.5} |
| 身份字段 | id/name/description/icon/unlock 转正式时自定义（现测试值：skill_雷火_2 / 飞火流星(测)） |

**JSON 块（对照校验）**

```json
{
	"id": "skill_雷火_2", "name": "飞火流星(测)",
	"element": "雷火", "type": "active", "operator": "OP_AIM",
	"energy_cost": 20, "cooldown": 10.0,
	"tags": ["ball_dmg_up_pct", "ball_speed_up_pct"],
	"tag_params": {
		"ball_dmg_up_pct": {"value": 40.0},
		"ball_speed_up_pct": {"multiplier": 1.5}
	}
}
```

**数值可调范围**：value 20~60；multiplier 1.2~2.0。

## 保真三原则（调数值前必读）

1. **tags 组合别动**：加减标签=新技能（要重新测试）；只调 tag_params 数值=安全
2. **tag_params 键名与结构别动**：参数键名错一个字符=参数丢失，技能变摆设（金刚_1 事故）
3. **数值别走极端**：低于建议下限 AI 不出手；耗能超 30 出手率暴跌（大招 ≤50）

## 通用字段建议

- unlock_level/unlock_cost：测试技 1/0，转正式按商业化设计定
- icon_path/icon_color：现空/白色，转正式时配置
- 被动技：type=passive **不进 AI 主动释放池**（事件自动触发），trigger 字段按被动规范另填
- 操作方式速查：球强化=OP_AIM／自动效果=OP_AUTO／引导球=OP_STEER／空中干预=OP_MIDFLY／开关护盾=OP_TOGGLE
- 新技能配好想给 AI 用：先跑释放统计（或技能规划侧抽检）确认"AI 会用"再算完成
