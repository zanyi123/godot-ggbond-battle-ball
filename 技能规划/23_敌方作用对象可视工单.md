## 一、问题与范围

### 1.1 缺口（现状）
- 19 批图标条只绑 **A 队三人**（battle_hud 面板），B 队敌人身上被挂的标签效果**无任何屏幕显示**
- 影响验收：AI 完全体释放印记/减速/定身类命中 A 队不可见（方向反了），A 队技能命中敌人也看不见敌人被挂了什么——**双向都缺敌方侧反馈**
- 22-3 抽检三轮已实证：效果在判定层落地（日志级可见），屏幕不可见

### 1.2 作用对象=敌方的标签清单（25 条，全部需敌人头顶可视）

**on-hit 随球类（11 条，registry on_hit=true）**：
`player_mark_apply`(印记·层数角标) / `player_move_slow`(减速) / `player_stun`(眩晕) / `player_silence`(沉默) / `player_disarm`(缴械) / `player_root`(定身) / `player_hp_dot`(持续伤害) / `player_vulnerable`(易伤) / `player_heal_block`(禁疗) / `player_energy_block`(禁能) / `player_reveal`(显形)

**直接释放减益类（14 条，registry target 参数=enemies）**：
`player_atk_down_pct/flat` / `player_def_down_pct/flat` / `player_spd_down_pct/flat` / `player_res_down_pct/flat`（属性削弱×8）/ `player_element_weak`(元素弱点) / `player_energy_max_down_pct/flat`（能量上限削减×2）/ `player_spirit_cd_up` / `player_spirit_cost_up`

**已登记 allies 语义的支援类（8 条）不做敌方显示**（energy_share/energy_max_up/spirit_cost_down/cd_down/uses_up/double/half——作用于己方，19 批图标条已覆盖）。

## 二、方案（双轨，复用 19 批组件与配色）

### 2.1 敌人头顶状态条（主交付）

- **组件复用**：`StatusIconBar`（19 批交付）本身支持 `bind_player(任意球员)` + 全套信号（status_lights_changed/mark_changed）——敌方可视=**为 B 队球员各建一条 bar，数据源换绑敌方 player**，配色/单字/层数/秒数角标与 A 队同图例（主人验收零学习成本）
- **敌我区分**：敌方条加**红色系边框/底色带**（一眼区分敌我），图例字符不变
- **显示规则**：只显示"当前生效的减益/控制"（即 STATUS_ICONS 中敌方相关键）；无状态时不显示（避免常驻空条）

### 2.2 双轨载体（沿 09-24 裁定）

| 轨 | 载体 | 说明 |
|---|---|---|
| **2D 兜底（主实现）** | 2D 层：B 队球员头顶跟随条（复用球员头顶既有挂点模式 avatar_label 同位） | battle_hud 外的独立 CanvasItem，每帧跟随敌球员屏幕坐标 |
| **3D 主** | Label3D/小 mesh 组挂在 player_proxy_3d 头顶（bridge `_attach_name_label` 同位上方，y≈80） | 3D 模式下可见；bridge roster 循环同款跟随 |

### 2.3 数据流（零判定）

```
敌方 player（B队）──status_lights_changed / mark_changed──→ EnemyStatusMarker（只读快照渲染）
                                ↑ 数据唯一来源=player._status_lights（无 target 时 self 语义不变）
```

## 四、验收断言清单（≥8 项，headless 可跑）

1. B 队敌人被 `player_mark_apply` 命中→头顶标记出现"印"绿标+层数=1；再命中→层数=2
2. `player_stun` 命中→"晕"红标出现；到期→消失
3. `player_heal_block`→"疗"紫标；`player_move_slow`→"慢"标（慢=敌我同图例，字表 §2.0）
4. A 队球员自增益→**A 队图标条**出现（敌方标记不出现在 A 队球员头上——敌我分流正确）
5. 标记跟随移动（B 球员位移→标记同步头顶）
6. 到期/被驱散→标记消失
7. UI 零判定 grep（敌标记组件无任何写操作）
8. 全量回归不回退 + run_sim 3 场危险=0（纯可视零行为）

**实机项（主人）**：3D 模式目验敌头顶标记观感、大小/高度是否遮挡（参数可调）。
