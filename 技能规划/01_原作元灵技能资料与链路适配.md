## 二、本项目技能系统六阶段链路（2026-09-17 代码实况）

> 一次主动技能从按下按键到画面生效的完整路径。每环节标注：文件 / 状态（✅已有 / ❌未有）。

### 阶段0：比赛前——数据装载与装备
| 环节 | 系统/文件 | 状态 |
|---|---|---|
| 技能/元灵数据定义 | `data/spirits/skills.json`（运行时9条）+ `data/spirits/spirits.json`（6元灵）+ `data/spirits/tags_registry.json`（80标签） | ✅ |
| 大厅选元灵/解锁装备 | `scripts/systems/spirit_system/spirit_ui.gd` | ✅ |
| 上场注入 | `battle_manager.gd` 开局挂技能到球员 | ✅ |

⚠ **数据双源分裂**：`data/skills/skills.json`（旧20条，values风格）是**死数据**，无脚本加载——多元化前必须归档，唯一数据源=`data/spirits/skills.json`。

### 阶段1：资格判定
| 环节 | 系统/文件 | 状态 |
|---|---|---|
| 玩家按键 | `skill_state_manager.gd`（IDLE/ACTIVATED/RELEASING/COOLDOWN，双击自动放） | ✅ |
| AI 释放 | `spirit_ai_manager.gd` 评分选技，走同一判定管道 | ✅ |
| 资格链 | `spirit_skill_trigger.gd use_skill()`：上场→冷却→能量→被动禁手动 | ✅ |
| 指定落点技能 | 鼠标放置模式等点击坐标 | ✅（且**目前是区域类唯一触发方式**） |

### 阶段2：翻译分发
- `spirit_skill_trigger.gd _build_tag_params()`：tags[]+tag_params{} → 带上下文参数（_skill_id/_caster_id/_element/_target_data）。✅
- 目标选取：self/enemies/allies/nearest_enemy。✅（队友粒度待确认）
- 执行顺序：handler 内 `_tag_priority` **硬编码优先级表**。✅（新增标签必须手工登记，漏了会乱序）

### 阶段3：三路线执行（中枢=`spirit_tag_effect_handler.gd` 约1200行/80 case）
| 路线 | 机制 | 状态 |
|---|---|---|
| ①对球 | 写 `_ball_mods` 修饰符清单 → 投球时灌入 ball → `ball.gd` 飞行消费（加速/增伤/追踪/回旋/穿透/AOE）+ 命中后效果（先例：寒冰减速） | ✅；⚠已知缺陷：清单全局共享，A开增益B投球也吃到（**修新技能前置**） |
| ②对球员 | `player.gd` 六层管道：Buff数值层/控制状态灯(免控+互斥)/持续tick/技能倍率/检查链/标签层 | ✅ 带成套测试 |
| ③对场地 | ObstacleManager(障碍)/FieldZoneManager(区域四类✅)/IllusionManager(幻象✅)；6个空pass（obs_move/lock、terra_change/revert、zone_mark/clear） | 部分✅ |

### 阶段4：结算与广播
- `ball.gd` 命中/弹墙/停球信号 → `event_bus.gd`（17事件六类）。✅
- 被动技能：trigger 订阅事件→条件检查（单条件）→CD→自动放。✅（先例：坚韧不拔=Defend.BOUNCED）
- 球权裁决：E7v2 规则（内场停回攻击者/外场吸附/接住夺权），独立于技能系统。✅

### 阶段5：表现
- 2D：`skill_visual_manager.gd` 轮廓环/条带（按 target_type 自动）。✅
- 3D：`skill_fx_3d_adapter.gd` 订阅 skill_triggered → 挂 SkillOutline3D 轮廓。✅；**粒子特效层 ❌未有**（纸面方案 docs/技能特效链路方案.md；Binbun包已导入未接线；external/GODOT-VFX-LIBRARY 约30粒子场景未入库）
- sim 模式强制纯 2D 无 3D 层（刻意设计）。✅

## 三、模板案例逐站走位（示范"案例→链路"的分析格式）

### 案例1 回旋火星（菲菲·玲珑）——模板A 纯数据
`阶段0 新JSON → 阶段1/2 全✅ → 阶段3 路线①修饰符"回旋"(✅ball_boomerang已有消费点) → 阶段4 球权自洽(飞回=回手/被接=夺权) → 阶段5 轮廓✅`
**结论：纯写数据。风险仅：回旋+球权组合跑 sim 确认。**

### 案例2 蔓藤缠绕（波比·小圣）——模板A+ 命中生效
`阶段0 新JSON → 阶段3 路线① on-hit管道(✅先例=寒冰减速) 挂 player_root(✅状态灯) → 命中才定身`
**结论：机制现成。动手前确认：on-hit 管道是通用清单还是写死减速（写死则小改一处）。官方细节"受击即解除"v1 简化为固定时长（on_hit_expire 原语记台账 #21）。**

### 案例3 火凤燎原（菲菲·玲珑元灵模式）——模板E 场地触发
`阶段0 新JSON → 阶段3 路线③ danger区(✅)+持续掉血(✅player_hp_dot)；❌缺口=区域只认鼠标坐标，需"球停点触发"（ball停球信号✅已有→坐标注入入口❌开一个）；AI 不躲区(❌v1接受)`
**结论：一次基建解锁所有"落点型"技能（灼热轨迹/毒圈/治疗圈）。**

### 案例4 移形换影（莉莉）——模板A 纯数据（2026-09-19 勘误降级）
官方描述实测："大幅度增加移速，减轻期间受到伤害"——**不是换位**！
`阶段0 新JSON → 阶段3 路线② player_spd_up_pct(✅) + player_def_up_pct(✅) → 纯数据`
**结论：原"player_swap_pos 新原语"判断作废，V1 少做一个原语，直接排产。**

### （进阶备忘）暗黑复制/黑白旋涡（黑洞队）——复制系
需"最近敌方技能"快照+复制执行改写，动 trigger 管道，二批。原作黑洞队全队围绕复制系（巨变射线/暗黑复制/暗黑共享/黑白旋涡/二重黑白旋涡+卜三卜四"梦幻束缚"反制复制）。
