## 原语卡（2 个）

### #6b 削能墙 drain_wall
- 三问：场地（障碍实体）/ T1 释放或 spawn_at / 持续 duration
- 机制：生成"吸力墙"障碍——球进入捕获半径 → **被吸向墙心并扣住** → 按岩石墙消耗规则**逐帧削攻击与球速** → 球速/攻击耗尽（消散/停止，走既有停球球权规则）或 parameter 上限到（释放继续飞）
- 与岩石墙差异 = 吸力（捕获半径内球矢量偏向墙心）+ 不做"击穿"（削完即止）——消耗规则**复用既有** `attack_consume_rate/speed_consume_rate` 口径
- 标签：`field_drain_wall`（params: duration, width, height, capture_radius, drain_rate）
- 落点：`field_route.gd` 加 case + 障碍子类（挂 ObstacleManager 体系，与岩石墙同基类）
- 断言：捕获半径内球被吸入（矢量偏向）、逐帧削能数值正确、耗尽停球走既有球权、parameter 上限释放继续飞、球不被传过墙、玩家/AI 路径一致
- 解锁：风之屏障、野狼风墙（蒙面侠队）

### #6a 地形改动 terra_change（空 pass 转正）
- 三问：场地（区域）/ T1 或 spawn_at / 持续 duration
- 机制：指定区域内改摩擦系数（冰面滑动）——`field_terra_change` 空 pass 转正，落点 = **field_physics_manager 既有接口**（摩擦/弹性已实现且带自恢复 Timer，工单只做"区域化调用"：设置区域参数 + duration 到恢复）
- 标签：`field_terra_change`（params: friction_scale, duration, radius, pos 或 spawn_at）
- 断言：区域内移动/球滚动摩擦变化（可感知滑动）、到期恢复原值、区域外不受影响、与削能墙/障碍共存
- 解锁：冰面领域（冰系区域滑动）
- 边界：弹性改动接口预留不实现（无官方用例，防过度工程）；塌陷类归 C 类 S10 不做
