## 原语卡（6 个）

### #11 禁疗 heal_block（含禁能）
- 三问：球员 / T2 命中后作用于目标 / 持续 N 秒
- 机制：目标加阻断标志，期间**一切体力恢复无效**（regen tick、治疗函数入口检查）；禁能同构（能量恢复阻断）
- 标签：`player_heal_block`（params: duration）、`player_energy_block`（params: duration）
- 消费点：player.gd 恢复入口（regen tick + heal）加标志检查
- 断言：禁疗期回血无效且不转存、到期自动恢复、禁能同构
- 解锁：蝰蛇毒咬、麒麟火层2

### #5 反伤 reflect
- 三问：球员 / T2 被击中时 / 瞬时返还
- 机制：take_damage 结算尾部（伤害成立后）向攻击者返还 X%
- 标签：`player_damage_reflect`（params: pct, duration）
- 关键：**递归护栏**（反伤伤害不再触发对方反伤，防死循环）
- 断言：返还比例正确、双方带反伤不循环、反伤致死结算正常
- 解锁：荆棘护甲、滑溜溜护甲

### #16 元素免疫/弱点
- 三问：球员 / 持续 / 防御域
- 机制：player 加元素状态列表 `[{element, mode:immune|weak, expires_at}]`；take_damage 元素判定处（既有克制×1.3 旁）加：immune→×0、weak→×参数倍率
- 标签：`player_element_immune`（params: element, duration）、`player_element_weak`（params: element, multiplier, duration）
- ⚠ **不动 elements.json 结构**（克制环数据是全局的，免疫是个人状态——分界写死）
- 断言：免疫归零、易伤倍率、到期失效、与既有克制的乘算顺序（先克制后免疫）
- 解锁：寒冰呼啸、滑溜溜护甲、水瓶封印

### #19 能量分摊 energy_share
- 三问：球员 / 持续 / 资源域
- 机制：持有者 A 挂分摊状态并指定受益队友 B → B 释放技能扣费时，share_pct 由 A 支付（A 能量不足则 B 全付或释放失败——按现有能量不足语义）
- 标签：`player_energy_share`（params: share_pct, duration, target:ally）
- 断言：分摊比例、A 能量不足时回退、多队友同时挂取先
- 解锁：惊雷响应×2

### #20 储存多段 charge_stock
- 三问：技能属性扩展（非 buff）/ 释放时消费 / 按时间充能
- 机制：**两个方案，实施时择一**（拿不准问主人）：A. 技能 JSON 加 `charges:{max, recharge_time}` 字段，trigger 扣充能（推荐——属技能属性非状态）；B. 标签管道挂 player 计数器
- 断言：充能速率、满储上限、释放扣一道、无充能不能放
- 解锁：慢悠悠光线（6 道）

### #21 受击解除 on_hit_expire
- 三问：**参数级原语**（非独立标签）/ T2 持有者被命中 / 即时
- 机制：各状态类标签的 tag_params 支持通用开关 `on_hit_expire: true` → 该状态登记标记 → take_damage 命中处理时清除所有带标记状态
- 改动：player 状态登记处支持标记 + take_damage 清除逻辑 + 文档（registry params 说明）
- 断言：命中解除带标记状态、未命中持续、不带标记状态不受影响
- 解锁：蔓藤缠绕细节（受击即解）
