## 一、链路全景与缺口盘点（为什么只有三份）

一条技能的 8 段链路：**创建→装备→激活→释放→传递→命中→生效→可视**。

| 段 | 已有覆盖 | 缺口 |
|---|---|---|
| 创建 | dev_skill_save 14/14 + sys_e2e 10/10 | — |
| 装备 | match_e2e + skill_bar_dynamic 11/11 | — |
| 激活 | routing 21/21 + op1_patch 40/40 | — |
| 释放 | wave3~6 + batch1/2 逐标签 | — |
| 传递 | ball_mods 9/9 + on_hit_chain 10/10 | — |
| 生效 | 各 wave 管道 | — |
| 可视 | basic_ui 29/29 | — |
| **命中→落地（接缝）** | on_hit_chain（handler 级） | **场景级真球真打未验** |
| **判定→可视反射（接缝）** | basic_ui（信号级） | **真场景串测未做** |
| **组合整体（存量）** | batch 级（零件） | **63 条可产技无整机抽检** |

→ 缺口=2 条接缝 + 存量抽检 = 三份子工单。
