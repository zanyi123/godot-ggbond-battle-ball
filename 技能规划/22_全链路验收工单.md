## 一、链路全景与缺口盘点（为什么只有三份）

一条技能的 8 段链路：**创建→装备→激活→释放→传递→命中→生效→可视**。

| 段 | 已有覆盖 | 缺口 |
|---|---|---|
| 创建 | dev_skill_save 14/14 + sys_e2e 10/10 | — |
| 装备 | match_e2e + skill_bar_dynamic 11/11 | — |
| 激活 | routing 21/21 + op1_patch 40/40 | — |
| 释放 | wave3~6 + batch1/2 逐标签 | — |
| 传递 | ball_mods 9/9 + on_hit_chain 10/10 | — |
| 生效 | 各 wave 管道 | — |
| 可视 | basic_ui 29/29 | — |
| **命中→落地（接缝）** | on_hit_chain（handler 级） | **场景级真球真打未验** |
| **判定→可视反射（接缝）** | basic_ui（信号级） | **真场景串测未做** |
| **组合整体（存量）** | batch 级（零件） | **63 条可产技无整机抽检** |

→ 缺口=2 条接缝 + 存量抽检 = 三份子工单。

## 二、子工单卡

### 22-1 金路径场景测试（封缝1+缝2，最高优先）

**干什么**：照 match_e2e 模式（launcher+driver 现成）建 `test_golden_path.gd`：真实 battle_arena 场景内——
1. 装备玲珑（含飞火流星(测)/蔓藤缠绕(测)）→ 开赛
2. 释放印记球技（冰霜粉末式 mark_apply 随球技）→ 投球命中 B 队球员
3. 断言：**被打者 get_mark_count≥1**（整机级效果落地）+ **HUD 图标条出现"印"字图标**（判定→可视反射）
4. 反例：投球未命中（无人区）→ 暂存清空、被打者无印记

**文件**：`tools/golden_path_launcher.tscn`（新）+ `tools/golden_path_driver.gd`（新；复用 match_e2e_driver 装配/断言模式）
**验收**：断言 ≥5/5 + 现有回归不回退

### 22-2 on-hit 矩阵（同管线 11 条逐个验证）

**干什么**：`test_on_hit_chain.gd` 扩展——11 条 on_hit 标签（印记/减速/眩晕/定身/禁疗/禁能/中毒/易伤/显形/缴械 + 已验印记）逐条：暂存→消费到受害者→**按各自落地方式断言**（眩晕=stunned 灯、减速=speed 数值降、禁疗=heal() 返回 0、中毒=hp 持续掉……），不以"success=true"糊弄。

**文件**：`test_on_hit_chain.gd` 扩展（同管线纯数据行）
**验收**：11 条断言全过（合计 ≥21/21）

### 22-3 存量滚动抽检（清旧账，挂 AI 完全体节奏）

**干什么**：63 条可产/简化技按三路线（BALL/PLAYER/FIELD）抽样，真场景整机跑（AI 完全体释放→行为/可视对照《21 对照表》）。每轮抽 3~5 条滚动，抽到问题按 bug_fix 另立修复。
**文件**：抽检记录表（本档 §五追加）+ 复用 golden_path_launcher
**验收**：滚动进行，无硬性截止；每轮回写记录
