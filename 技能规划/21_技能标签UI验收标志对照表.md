# 21 · 技能标签 → UI 验收标志对照表（AI 完全体观测用）

> 用途：AI 完全体在 **3D 演示平台** 使用技能时，按本表核对"释放了什么技能 → 屏幕上应该出现什么"。

## 一、三条验收通道（看哪里）

| 通道 | 位置 | 3D 模式下可见性 |
|---|---|---|
| **① HUD 状态图标条** | 屏幕下方三球员面板右上角（24px 色块+秒数/层数/次数点） | ✅ 永远可见（屏幕空间） |
| **② 世界空间叠加件** | 场景内（贴地区域色块/障碍色块/盾弧·盾体/球体半透明/必中线） | ✅ 2D 叠加件在 3D 画面上以平面块呈现；盾 3D 体为立体件 |
| **③ 自然行为可见** | 无专属 UI，靠行为本身 | ✅ 球速变快/折返/分裂/拖人等发生即见 |

**3D 模式注意**：球员头顶 2D 状态灯（avatar 的 state_indicator）在 3D 模式被隐藏——**控制类状态请看通道①图标条**（晕/锢/默/缴都有专属图标）。

## 二、HUD 图标条图例（通道①）

每图标 = 底色块 + 中央单字；右上角数字=剩余秒数；右下角数字=层数；底部小圆点=充能 N/M。

| 图标字 | 底色 | 含义（触发标签） |
|---|---|---|
| 疗 | 紫 | player_heal_block 禁疗 |
| 能 | 蓝灰 | player_energy_block 禁能 |
| 反 | 橙红 | player_damage_reflect 反伤 |
| 免 | 白框 | player_element_immune 元素免疫 |
| 弱 | 暗红 | player_element_weak 元素弱点 |
| 摊 | 青 | player_energy_share 能量分摊 |
| 储 | 蓝 | player_charge_stock 储存（底部点=剩余 N/M） |
| 印 | 绿 | player_mark_apply 印记（右下角=当前层数；**叠层瞬间整条闪烁2次**） |
| 盾 | 金 | player_shield_obstacle 盾（uses 模式底部点=剩余次数；2D 弧面+3D 盾体同步在场） |
| 隐 | 灰 | player_stealth 玩家隐身 |
| 无 | 黄 | player_invincible 无敌 |
| 晕/锢/默/缴 | 红/褐/紫/橙 | player_stun/root/silence/disarm 控制类 |
| T | 黄 | toggle 激活中（开关型技能常驻，关闭即摘） |

> 挂=状态出现；摘=到期/被驱散/宿主消失；秒数每整秒递减。图标条数据源全为只读信号，**UI 上有图标=判定层确实生效**。

## 三、BALL 路线（球侧标签——看球的行为与球体外观）

| ball_dmg_down / speed_down | 对称变慢/变弱（敌方施放时观察） | ③ |

| ball_avoid | 球绕开路径上的阻挡 | ③ |
| ball_boomerang | 球飞到距离阈值**折返飞回**投掷者 | ③ |
| ball_straight | 球轨迹无视干扰直线飞行 | ③ |
| ball_lockon | 球锁定指定目标飞去 | ③ |

| ball_spread | 球过半场/触发点**分裂为多球**扇形飞出 | ③ |
| ball_bounce_enhance | 球撞墙反弹且次数超过普通（最多 N 次参数可见） | ③ |

| ball_in_flight_boost | 球飞行途中**再按技能键**→速度/伤害二段提升 | ③（配合 MIDFLY 操作） |

## 六、操作方式（operator）反馈对照——释放"怎么操作"的可视部分

| operator | 释放时屏幕反馈 |
|---|---|
| OP_AIM 瞄准 | 激活→**方向预览虚线**贴地跟随鼠标（3D 载体/2D 兜底）→左键确认沿方向释放 |
| OP_POINT 点选 | 激活→选点态（悬停目标**目标圈**高亮能力已备）→左键锁定生效 |
| OP_STEER 操控 | 投出后**鼠标实时引导球/元灵体方向**（A/D 偏转增量、空格=跳/升按技能） |
| OP_TOGGLE 开关 | 激活→效果常驻（如盾出现）；**再按切形态/关闭**（图标条 T 常驻期间=开启中） |
| OP_MIDFLY 干预 | 投出后**再按技能键**触发拉回/推进（次数耗尽按键无效果） |
| OP_KEY_JUMP 跳跃 | 空格触发（如水鲨鱼跳出地面） |
| OP_PLACE 放置 | 鼠移预览跟随→左键放置 |
| OP_AUTO / 其余 | 激活即释放，无额外交互反馈 |

## 八、快速验收流程建议（AI 完全体跑场时）

1. 盯**图标条**：AI 释放 PLAYER 类技能→对应字符图标出现+秒数走动=判定生效 ✅
2. 看**球**：BALL 类技能→球的行为变化（加速/折返/分裂/半透明/拖人）✅
3. 看**地面**：FIELD 类技能→色块出现+名称+倒计时 ✅
4. 盾类：图标条盾金 + 场内弧面/盾体双确认 ✅
5. 对照本表"现状标注"区分：没看见=未实施（表七） vs 看见了但不符合=bug（报实施窗口）
