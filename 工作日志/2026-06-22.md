### 今日完成

**球员3D素材导入流程打通（4套带贴图+骨骼动画的GLB）**
- 主人按 v5.2 教程做完了素材：即梦生T-pose图→混元图生3D→Blender转FBX→Mixamo自动绑骨+下4套动作
- 素材落地：`assets/characters/avatars/` 下 4 个 GLB（Idle/Jog_Forward/Goalie_Throw/Goalkeeper_Catch），每个~95MB，含贴图+骨骼+动画

**关键坑1：Godot 配置**
- Godot 4.x 扫描到项目目录下的 `.blend` 文件想自动调 Blender 转换，但没配 exe 路径 → 报错
- 解决：Editor Settings 里禁用 blend 导入（方案A），不走 .blend 直导路线

**关键坑2：Mixamo 导出丢失贴图（白膜问题）**
- 现象：Mixamo 下载的 FBX 在 Godot/Blender 里都是白膜（全身通粉）
- 根因定位：原始混元 GLB（79MB）完整带3张贴图（baseColor/normal/metallicRoughness），但 Mixamo 处理过程中贴图丢失，FBX 只剩默认材质
- 解决：Blender 中转合并 —— 用脚本导入"FBX(骨骼+动画)"+"GLB(贴图)"，把 GLB 材质赋给 FBX 网格，导出 GLB

**关键坑3：Blender 5.1.2 的 FBX 导入器 bug**
- 报错：`'CyclesLightSettings' object has no attribute 'cast_shadow'`
- 位置：`G:/Blender/5.1/scripts/addons_core/io_scene_fbx/import_fbx.py:2254`
- 原因：Blender 5.1 API 移除了 `cycles.cast_shadow`，但 FBX addon 还在用旧 API
- 解决：直接改 Blender 自带模块那一行，加 `hasattr` 守卫（永久修复，1行）

**关键坑4：Blender 5.1 gltf 导出参数变更**
- 5.1 废弃了多个老参数：`export_textures`/`export_animation` 全失效
- 正确参数：`export_animations`（带 s）+ `export_materials='EXPORT'`
- 另：`bpy.ops` 在 background 模式下需显式 select+active 才能正确导出

**自动化脚本**
- 新建 `建模素材库/scripts/merge_texture_anim.py`：Blender 命令行脚本，自动合并贴图+动画为 GLB
- 流程：clear_scene → import_fbx → import_glb → 删 GLB 网格只留材质 → 赋材质给 FBX 网格 → export_glb
- 命令：`blender --background --python merge_texture_anim.py -- <fbx> <glb> <out.glb>`
