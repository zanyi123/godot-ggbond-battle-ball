## 激活条件
每次对话结束前，用户要求"写日志"时激活此技能。

## 核心功能
按照规范格式整理工作内容到当日工作日志。

## 使用方法

### 方法1：对话结束后自动提示
```
用户：写日志
→ 加载 write_log 技能
→ 读取当日工作日志文件：工作日志/2026-XX-XX.md
→ 按规范格式整理内容
→ 更新文件
```

### 方法2：技能调用
```
技能：write_log
→ 自动整理当天对话内容
→ 生成规范格式日志
→ 输出到 工作日志/2026-XX-XX.md
```

## 输出格式

```markdown
# 决竞球 Battle Ball - 工作日志

## Tips（置顶）
- 每次对话写入当日工作日志
- 记得更新前一天的任务状态

---

## 2026-XX-XX

### 今日完成
- [完成点1]
- [完成点2]
- [完成点3]

### 待完成任务
- [ ] [待办1]
- [ ] [待办2]

### 下一步方向
- [方向1]
- [方向2]

---
```

## 要求
- 简洁列表：每行一个实现点
- 不写代码：不贴代码块、不写详细步骤
- 不写几百行：通常20-30行以内
- 聚焦成果：只写完成了什么，不写过程细节

## 技巧
- 用动词开头：完成、修复、新增、重构、实现
- 用简短描述：如"新增发球速度差异化"而不是"发球速度差异化功能的完整实现"
- 分类整理：相关内容放在一起
- 标记状态：用✅或[x]表示已完成，[ ]表示未完成
