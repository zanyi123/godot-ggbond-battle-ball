# 10 完全体AI测试平台工单 —— 3v3 专测场：完全体AI验证 + 技能导入

> 主人需求（2026-09-26）：另搭一个 3v3 测试平台，专门验证**完全体AI**（球员AI+技能AI全系统）并**导入技能使用**。
> 执行窗口：**平台窗口**（新开，文件以新建为主可并行）；涉及 battle_manager 最小 flag 改动归**集成窗口单写者**。
> 前置：08 开关基建（✅）、集成接线（✅）；操控族实机验证部分等首个操控技能实配。

---

## 一、定位：sim 的超集，不是第二个 sim

既有资产盘点（不重复建设）：

| 既有 | 能力 | 缺口（=本平台要补的） |
|---|---|---|
| battle_arena + `--sim`（auto_simulate） | 双队全AI自动跑+健康指标（run_sim 门禁） | 无实机观测（headless/强制纯2D）、无技能导入配置、无决策可见性 |
| run_sim.sh + baseline | 确定性回归门禁 | 只看指标不看"像不像样" |
| dev_spirit_panel（元灵管理） | 技能编辑落盘 skills.json | 无"一键给某球员配某套技能"的测试装载 |
| switches.json + registry | 波次开关/止血阀 | 无运行时热切 UI（改文件才生效） |

**平台 = 复用 battle_arena 全部逻辑 + 三个新增能力**：①双队全AI观察模式（不强制纯2D，实机可看）②技能装载配置化（test_loadouts.json）③观测层（决策/通讯/开关可视化）。

## 二、Phase 拆分

### P1 观察模式入口（集成窗口单写者认领 battle_manager 最小改动）

- `battle_manager` 增加 `full_ai_observe: bool = false`（CLI `--fullai` 置位）：自动开始比赛 + `set_controlled_player(null)`（复用 sim 既有路径）+ **不强制纯 2D**（与 sim 的区别：`USE_3D_SCENE and not auto_simulate` 旁路改为 `and not auto_simulate and not full_ai_observe`，一行）
- 其余零改动：AI 链路、开关、门禁全部复用
- 验收：`--fullai` 进场=双队全AI自动开打、3D 可观、既有 sim 门禁不受影响（`--sim` 行为逐位不变）

### P2 技能装载配置化（平台窗口，新文件）

- `data/systems/spirit_ai/test_loadouts.json`（新）：
```json
{
  "schema_version": 1,
  "loadouts": [
    { "slot": "A0", "character_id": "猪猪侠", "spirit_id": "雷火", "skills": ["skill_雷火_1", "skill_雷火_2"] },
    { "slot": "A1", "...": "..." }
  ],
  "_说明": "6 槽位（A0-A2/B0-B2）；skill id 必须存在于 skills.json；空 loadout=用角色默认配置"
}
```
- `scripts/test3d/full_ai_platform/loadout_loader.gd`（新）：启动时读取→校验（id 存在/type 合法/operator 合法/能量>0，非法项打印+跳过该槽 fail-closed）→经既有装备链路上身
- 验收：配一套含各 operator 模式的技能（大惊雷=AIM/黑白旋涡=POINT/绝对控制=STEER/坚果盾=TOGGLE/二段推进=MIDFLY…）→平台实机各波表现可观测——**这正是操3矩阵的完全体验证场**
- 与波C联动：装载操控族技能后，ai_input_source 的激活窗 tick（集成备案②）即可触发验证——**本平台P2是备案②工单的前置**

### P3 观测层（平台窗口，新文件）

| 组件 | 内容 | 数据源（全部只读既有口） |
|---|---|---|
| 决策面板 | 每AI每周期：候选技能评分 top3/胜者/阈值判定/timing_gate 通过与 bonus/开关状态 | spirit_ai_manager 决策数据（新增只读 dump 口，归集成窗口最小改动） |
| 通讯日志 | 谁在何时发了什么消息、谁消费了（现只有气泡一闪而过） | comm_system（message_sent 信号已有） |
| 开关热切 | 面板按钮/热键改 waves 开关即时生效（改文件+registry.reload_switches()） | 08 已有 reload 口 |
| 跟随镜头 | 可选：镜头锁定某 AI 观察其走位+放技能 | 3D 相机既有 |

### P4 验收

- headless：平台自动模式跑通 3 场，指标走既有门禁（危险=0）；switches 热切后下一决策周期生效（断言）
- 主人实机清单：①`--fullai` 观战 ②换 loadout 重开=技能生效 ③热切波次=AI 行为即变 ④决策面板与实机行为对得上
- 回归保障：`--sim` 路径与 baseline 逐位不变（平台不得污染 sim）
